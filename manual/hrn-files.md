# 比較の状態を保存する (.hrn)

並べ方や表示の設定を、**`.hrn` ファイル**に保存して、あとで同じ比較を再開できます。

## この章でできること

- 比較の状態を保存して、開き直す。
- `.hrn` を、テキストエディタで書く。

## 保存と読み込み

- 保存: **ファイル > 保存** (File > Save) / **名前を付けて保存...** (Save As...)
- 読み込み: **ファイル > .hrn を開く...** (File > Open .hrn...) (<kbd>Ctrl</kbd> + <kbd>Shift</kbd> + <kbd>O</kbd>)、または、エクスプローラで `.hrn` をダブルクリックする (インストーラで関連付けた場合)。

保存されるのは、格子の形、画像セットの定義、セルごとの設定 (同期、倍率、ガンマ、回転、反転、チャネル、差分) です。

```{warning}
Heiran が保存するとき、ファイルは**書き直されます**。テキストエディタで書き足したコメントや、空行、キーの順は、残りません。
コメントを残したいファイルは、Heiran で上書き保存しないでください。
```

## 書き方

`.hrn` は、コメントを書ける、JSON に近いテキストです (キーの引用符の省略や、末尾のカンマも書けます)。
画像のパスは、`.hrn` のあるフォルダからの相対で書けて、`*` で複数のファイルをまとめて指定できます。

```
{
  format_version: 1,

  viewer: {
    layout: { rows: 1, cols: 3 },
  },

  images: [
    { name: "before", path: "before/*.png" },
    { name: "after",  path: "after/*.png" },
  ],

  cells: [
    { image: 0 },
    { image: 1 },
    // 3 つ目のセルへ、2 つのセルの差分を出す
    { diff: { base: 0, target: 1, mode: "absolute" } },
  ],
}
```

ファイルの中のラベルには、`{width}`、`{height}`、`{filesize:MB}` のような置き換えを使えます。
項目の一覧は、設計文書の「設定ファイル仕様」にあります (`docs/設定ファイル仕様.md`)。

## 読み込みで問題があったとき

書き間違いがあると、項目ごとの問題の一覧が出ます。重大な問題 (版の不正、必須の項目の欠落など) があると、読み込みは中止されます。
軽い問題 (範囲外の値、見つからない画像など) は、既定の値に置き換えて、続けて読み込まれます。
