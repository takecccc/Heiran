# Heiran マニュアル

Heiran は、複数の画像を並べて、**同じ位置を同じ倍率で見比べる**ための画像ビューアです。
パンとズームがすべての画像で連動し、違いを数値と図で確かめることもできます。

## このマニュアルについて

- 操作の手順を、画面の言葉 (メニューの名前など) で説明します。メニューの名前は、画面に出る英語の表記のまま書きます。
- キーの操作は <kbd>Ctrl</kbd> + <kbd>O</kbd> のように書きます。
- アプリの中の **ヘルプ > マニュアル** (Help > Manual) (<kbd>F1</kbd>) から、いつでも開けます。

```{note}
このマニュアルは、順次、書き足していきます。内容の足りない点は、順次、直していきます。
```
