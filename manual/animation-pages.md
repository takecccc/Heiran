# アニメーションと複数ページ

1 つのファイルの中に、複数の画像 (コマ) が入っている形式の見方を説明します。

## この章でできること

- GIF、WebP、APNG のアニメーションを再生する。
- 1 コマずつ進めて、コマを見比べる。
- 複数ページの TIFF や、パートを持つ EXR のページをめくる。

```{note}
この章の「コマ」は、ファイルの**中**の画像です。フォルダの中の別のファイルを順に見る「ページ」([並べて見る](side-by-side.md#ページを送る))
とは別の軸なので、キーも分かれています。
```

## 再生する

アニメーションのファイルを開くと、**表示 > アニメーションを再生** (View > Play Animation) (<kbd>P</kbd>) で再生と一時停止ができます。
**表示 > 前のフレーム** (View > Previous Frame) / **次のフレーム** (Next Frame) (<kbd>Ctrl</kbd> + <kbd>←</kbd> / <kbd>→</kbd>) で、1 コマずつ進められます。
ステータスバーに、現在のコマ (「フレーム 3 / 12」など) が出ます。

```{figure} _static/images/animation.png
:alt: アニメーションの GIF を開いた画面。ステータスバーに「フレーム 2 / 12」と出ている
:width: 100%

アニメーションを開いた画面。左下のステータスバーに、**ページ** (Page) (フォルダの中のファイル) と **フレーム** (ファイルの中のコマ) が並びます。
```

## 複数のセルで再生する

アニメーションを複数のセルへ並べたときの進め方を、**表示 > アニメーションの同期** (View > Animation Sync) で選びます (**設定 > アプリ設定…** (Settings > App Settings...) の **表示・再生** (Display and playback) にも同じ項目があります)。

```{list-table}
:header-rows: 1
:widths: 25 75

* - 設定
  - 内容
* - 自動 (Auto)
  - コマの数が同じなら、全セルを同じコマにそろえる。違うときは、それぞれの速さで再生する (既定)
* - 常に同期 (Locked)
  - 常に、全セルを同じコマにそろえる
* - 個別 (Independent)
  - 常に、セルごとに、それぞれの速さで再生する
```

コマ送りは、どの設定でも、全セルを同じコマにそろえます。

## 複数ページのファイル

複数ページの TIFF や、複数のパートを持つ EXR は、コマと同じ操作で、ページをめくります。
**表示 > 画像一覧** (View > Image List) (<kbd>T</kbd>) で、フォルダの中のファイルをサイドパネルから選べます。

```{figure} _static/images/pages.png
:alt: 画像一覧パネルのサムネイル表示
:width: 70%

画像一覧パネルのサムネイル表示。選ぶと画像が切り替わり、一覧は開いたままになります。
```

## 大きなアニメーションについて

とても大きなアニメーションは、メモリの使いすぎを避けるため、圧縮したまま持ち、必要なコマだけを展開します。
そのぶん、再生中に CPU を使います。切り替わる大きさは、**設定 > アプリ設定…** の **キャッシュ** (Cache) にある **アニメーションをストリーミングにする境目** (Animation streaming threshold) です。
