# はじめに

## Heiran でできること

- 複数の画像を、格子状に並べて表示します。
- ドラッグで動かす、ホイールで拡大縮小する、といった操作が、**並べたすべての画像に同時に効きます**。
  同じ場所を同じ大きさで見比べられます。
- マウスの下の画素の値を、並べた画像のすべてについて、同時に読み取れます。
- 画像の違い (差分)、明るさの分布 (ヒストグラム) などを、数値と図で確かめられます。
- PNG、JPEG、GIF、WebP、AVIF、JPEG XL、TIFF、OpenEXR、HDR、TGA、DPX、PSD などを開けます。
  16bit や浮動小数の画像も、元の精度のまま扱います。

## インストールと起動

Windows 用のインストーラ (`Heiran-<版>-win64.exe`) を実行します。ZIP の場合は、好きな場所へ展開して、`bin` フォルダの
`heiran.exe` を起動します。

更新するときは、Heiran を終了し、既存版と同じインストール先を選んで上書きします。
先に旧版をアンインストールする必要はありません。**インストール** (Install) を押す前にキャンセルしても、既存版は残ります。
ファイルのコピー開始後に更新が失敗した場合は、インストーラを再実行してください。旧版への自動復元には対応していません。

インストーラの **ファイルの関連付け** (File associations) では、エクスプローラーから Heiran を使うための設定を選べます。
ここで選択しなくても、対応する画像形式はすべて開けます。

- **.hrn の関連付け** (Associate .hrn sessions): 比較の状態を保存した `.hrn` ファイルを Heiran で開きます。
- **一般画像** (Common images): PNG、JPEG などの「プログラムから開く」の候補に Heiran を追加します。
- **高精度画像** (High precision): EXR、HDR、DPX、TGA の「プログラムから開く」の候補に Heiran を追加します。

すべて既定で選択されています。カテゴリのチェックで一括選択・解除でき、左側の展開ボタンから各拡張子を個別に選べます。
画像ファイルの既定のアプリは変更しません。このページではインストール容量を表示しません。

## 動作環境

Windows (64bit) と、**OpenGL 3.0 以上に対応した GPU** が必要です。Microsoft Visual C++ ランタイム (x64) も必要です。インストーラが、入っていなければ案内します。ZIP から使う場合は、最新の `vc_redist.x64.exe` ([Microsoft の配布ページ](https://aka.ms/vs/17/release/vc_redist.x64.exe)) を先に入れてください。

画面の言語は、英語と日本語です。OS の表示言語に従います。**設定** の **言語** で選べます (次に起動したときから変わります)。このマニュアルは、メニューやボタンの名前を、日本語の表示の名前で書き、初めて出るところに、英語の表示の名前を (括弧で) 添えています。英語の表示で使うときは、括弧の中の名前を見てください。画面の画像は、日本語の表示です。

起動のときに「OpenGL が使えない」と出たら、グラフィックスドライバを更新してください。
リモートデスクトップや仮想マシンなど、GPU のない環境では、動かないことがあります。

## 画像を開く

起動直後の画面には、始め方の案内 (ドロップ、**画像を開く...** (Open Image...) のボタン、キー、最近開いた画像) が出ます。画像を開くと、案内は消えます。

次のどれでも開けます。

- **ファイル > 画像を開く...** (File > Open Image...) (<kbd>Ctrl</kbd> + <kbd>O</kbd>) で、ファイルを選ぶ。複数のファイルを選ぶと、枚数に合う格子に並びます。
- 画像ファイルを、Heiran の画面へ**ドラッグアンドドロップ**する。
- エクスプローラで画像を右クリックして、「プログラムから開く」から Heiran を選ぶ。

画像を 1 枚だけ開くと、**同じフォルダにある、同じ種類の画像**を、「ページ」として続けて見られます。
開いた画像のページから始まります。ページを送る方法は、次の章で説明します。

起動直後は、画像を開くための案内と最近開いた画像を表示します。内容が収まらない場合は、案内の中をスクロールできます。

## 基本の操作

画像を動かす・拡大縮小する操作は、**並べたすべての画像に同時に効きます**。

| したいこと | 操作 |
| --- | --- |
| 元ファイルを別アプリへ渡す | <kbd>Ctrl</kbd> を押しながら画像をドラッグする |
| 画像を動かす | 画像の上でドラッグする |
| 拡大・縮小する | マウスホイールを回す (マウスの下の位置が、動かずに残ります) |
| 画面に収める | <kbd>F</kbd> キー、またはツールバーの「フィット」。画像をダブルクリックしても、フィットと等倍 (100%) が切り替わります 収めた状態で見ているあいだは、ウィンドウの大きさを変えても、収め直します (拡大したり動かしたりしたあとは、倍率を保ちます) |
| 等倍 (100%) にする | <kbd>1</kbd> キー、またはツールバーの「1:1」 |
| 表示を最初に戻す | <kbd>0</kbd> キー、またはツールバーの「リセット」 |
| 少しずつ拡大・縮小する | <kbd>+</kbd> / <kbd>-</kbd> |
| 次のページ・前のページ | <kbd>→</kbd> / <kbd>←</kbd>、<kbd>PageDown</kbd> / <kbd>PageUp</kbd>、<kbd>Space</kbd> / <kbd>Backspace</kbd>、マウスの「進む」「戻る」ボタン |
| 最初・最後のページ | <kbd>Home</kbd> / <kbd>End</kbd> |
| 全画面にする | <kbd>F11</kbd> (もう一度で戻ります。<kbd>Esc</kbd> でも戻れます)。全画面では、マウスを画面の上端へ寄せると、メニューとツールバーが一時的に出ます |
| 画像をコピーする | <kbd>Ctrl</kbd> + <kbd>C</kbd> |

```{tip}
拡大すると、画素が四角く見えます。これは、画素の値をそのまま確かめられるようにするためです。
滑らかに表示したいときは、**設定 > アプリ設定…** (Settings > App Settings...) の **表示・再生** (Display and playback) で、拡大のときの補間を **なめらか** (Smooth) にします。
```

## 画素の値を見る

**表示 > 画素の情報** を選ぶと、右側に **画素の情報** (Pixel Info) が開きます。画像の上でマウスを動かすと、

- 画素の位置 (`x`, `y`) とページ
- 並べたすべての画像の、その位置の画素の値 (R、G、B、A)
- マウスの周りの拡大図

が出ます。値の単位は、**表示 > 画素値の単位** (View > Pixel Value Unit) で、`0 - 255` と `0.0 - 1.0` から選べます。
画像の上には、すべてのセルで同じ位置を指す十字のカーソルが出ます。

画素の情報を閉じていても、**ステータスバー**に、マウスの下の位置と、各セルの値が短く出ます (`x=87 y=33  [1] 242 244 247  [2] 52 130 72`)。
セルが多いときは、先頭の 4 つと、残りの数 (`+3`) を出します。

```{figure} _static/images/pixel-info.png
:alt: 右側に画素の情報が開いた画面
:width: 100%

画素の情報。拡大図には、周りの画素の値が重なって出ます。下の欄に、セルごとの値が並びます (`[1]`、`[2]` はセルの番号)。
```
