# Heiran 1.1.1

複数の画像を並べて、同じ位置を同じ倍率で見比べるための Windows 用イメージビューアです。

## 変更点

- **全画面表示**。ツールバーのボタンやメニューでも Windows 標準のマウスポインターを表示できるよう、Qt の Windows 連携 API で全画面に 1 ピクセルの枠を設定しました。ポインターを画面上端へ寄せると操作バーが開きます。
- **レイアウト選択**。セル数の文字部分をクリックするか Enter を押すと、そのセル数で前回使った配置を適用します。マウスを重ねる、右端の矢印をクリックする、または右矢印キーを押すと、行×列の候補が開きます。
- **レイアウト変更時のちらつき**。表示済みの画像とセルを再利用し、配置とフィットを更新してから描画を再開します。行優先と列優先の切り替えでも、現在のページを維持します。
- **ヒストグラム**。グラフ上の横ドラッグで値の範囲を選び、該当画素を全セルの画像上で強調できるようにしました。R・G・B の成分を指定でき、画像上の矩形選択と組み合わせられます。

## 動作環境

- Windows (64bit)
- OpenGL 3.0 以上に対応した GPU とドライバ
- Microsoft Visual C++ ランタイム (x64)。入っていない環境では、インストーラが案内します。
  ZIP から使う場合は、先に [最新の vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) を入れてください

## 注意

- 実行ファイルには、コード署名をしていません。起動のときに Windows の SmartScreen が警告を出すことがあります。
  配布元とハッシュを確かめたうえで、「詳細情報」から実行してください。
- 使い方は、同梱のマニュアル (アプリの **ヘルプ > マニュアル**、<kbd>F1</kbd>) にあります。
