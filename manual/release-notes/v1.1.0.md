# Heiran 1.1.0

複数の画像を並べて、同じ位置を同じ倍率で見比べるための Windows 用イメージビューアです。

## 変更点

- **画像一覧とお気に入り**。サイドパネルにサムネイルとファイル名・寸法・サイズの詳細表示を追加しました。お気に入りへの一括登録・解除、絞り込み、一括コピー、選択ファイルのドラッグ＆ドロップに対応しています。
- **選択画像の比較**。複数選択した画像を同じ画面に並べ、一覧で各画像の表示セルを確認できます。「比較終了」で元のレイアウトとページに戻れます。
- **ビューアの操作**。全体のズーム倍率をパーセントで直接指定でき、全セルの回転、中ボタンドラッグ、ページ送りの循環に対応しました。セル数をクリックすると、そのセル数で最後に選んだレイアウトを適用します。
- **設定と表示**。独立した「設定」メニューを設け、テーマを選んだ時点でプレビューできるようにしました。スレート、サンド、さくらを追加し、狭いウィンドウでナビゲーションを2行にする設定も追加しました。
- **起動と設定の保存**。起動時の画像読み込みやデコードを並行化しました。アプリ設定と履歴は `%LOCALAPPDATA%\Heiran\Heiran.ini` に保存します。旧版でレジストリに保存した設定は、必要に応じて設定し直してください。
- **インストーラー**。関連付けを拡張子ごとに選択できるようにし、インストール開始時に旧版を削除する処理を廃止しました。

## 動作環境

- Windows (64bit)
- OpenGL 3.0 以上に対応した GPU とドライバ
- Microsoft Visual C++ ランタイム (x64)。入っていない環境では、インストーラが案内します。
  ZIP から使う場合は、先に [最新の vc_redist.x64.exe](https://aka.ms/vs/17/release/vc_redist.x64.exe) を入れてください

## 注意

- 実行ファイルには、コード署名をしていません。起動のときに Windows の SmartScreen が警告を出すことがあります。
  配布元とハッシュを確かめたうえで、「詳細情報」から実行してください。
- 使い方は、同梱のマニュアル (アプリの **ヘルプ > マニュアル**、<kbd>F1</kbd>) にあります。
