# Heiran 1.2.0

画像とフォルダの差分を確認する専用画面を追加しました。ウェルカムページや **ファイル → 比較…** から、比較を始められます。

## 変更点

### 画像の差分比較

- 画像ファイルを 2 枚指定するか、画像一覧で 2 枚選んで **画像差分を比較** を開きます。アプリ内では同じウィンドウが比較画面に切り替わり、**比較終了** または `Esc` で元のレイアウト、ページ、一覧の選択に戻ります。
- 画像を横並びにして差分を重ねたり、同じ位置で左右を交互に表示したりできます。**前の差分** と **次の差分**（`F7` / `F8`）で検出箇所へ移動できます。注目箇所は赤で示します。
- 3 枚目に **差分マップ** を表示できます。差の大きさを黒から白の濃淡で示し、マップの明るさは 1〜32 倍で調整できます。閾値、ブロックサイズ、強調の透明度はスライダーを動かしている間も反映されます。
- 既定は **RGB差（最大成分）** です。明るさ、色差（ΔE00）、構造的類似度（SSIM）でも比較できます。現在の条件で検出した画素数と、復号した元画像の画素の一致を別々に表示します。
- 透明度を含む画素値で比較する方法と、白または黒の背景に重ねた見た目を比較する方法を選べます。画素値で比較する場合、両方で完全に透明な画素の RGB 差を無視できます。
- 通常のビューアーの差分セルにも差分移動と点滅を追加しました。RGB差（`rgb-max`）は差分セルや範囲の差分ウィンドウで選べます。

### フォルダ比較と外部ツール

- 2 つのフォルダを指定すると、配下の同じ相対パスのファイルを比較します。変更あり、左だけ、右だけなどで絞り込み、変更ファイルを順に確認できます。画像以外のファイルは外部の差分ビューアーで開けます。
- 比較する画像やフォルダは、パスの入力、参照ボタン、ドラッグ＆ドロップで指定できます。
- TortoiseGit や `git difftool` からは、`heiran.exe --diff before.png after.png` で比較専用ウィンドウを起動できます。`--left-title` と `--right-title` でリビジョン名などを表示できます。

### 配色と設定

- 入力欄の背景と枠線を見直し、フォーカスや選択中の項目を見分けやすくしました。
- アプリ設定に **テーマ** ページを追加しました。ベース配色、ウィンドウ背景、操作面、入力欄、文字色、強調色を調整できます。プリセットを編集すると **カスタム** に切り替わり、変更をすぐにプレビューできます。
- アプリ設定の左下に **すべての設定を初期値に戻す…** を追加しました。確認後に全カテゴリへ初期値を反映し、**OK** で保存します。**キャンセル** で設定画面を開く前の状態に戻ります。
- 同梱マニュアルの **資料 → リリースノート** から、版ごとの変更点を確認できます。

### インストーラー

- Inno Setup に移行しました。新規インストールでは **現在のユーザー用** が既定です。**すべてのユーザー用** を選んだ場合は管理者権限が必要です。
- **ファイルの関連付け** ページで、`.hrn`、一般画像、高精度画像の関連付けを選べます。画像形式は拡張子ごとに指定でき、選んだ形式の **プログラムから開く** に Heiran を追加します。

## 更新時の注意

更新するときは Heiran を終了し、既存版と同じインストール範囲とインストール先を選んでください。v1.1.1 以前の NSIS 版から更新する場合は **すべてのユーザー用** を選び、既存のインストール先へ上書きします。

## 動作環境

- Windows 64 bit
- OpenGL 3.0 以上に対応した GPU とドライバー
- Microsoft Visual C++ ランタイム（x64）。ZIP 版で必要な場合は [Microsoft の配布ページ](https://aka.ms/vs/17/release/vc_redist.x64.exe) から入手できます。

実行ファイルは未署名のため、Windows の SmartScreen が警告を表示する場合があります。使い方はアプリの **ヘルプ → マニュアル**（`F1`）から確認できます。
