# 表示を整える

画像の見え方を調整する方法を説明します。この章の調整は、**見え方だけ**を変えます。画像のファイルは変わらず、
画素の値の読み取りやヒストグラムなどの解析にも影響しません ([解析する](analysis.md))。

## この章でできること

- 見るチャネル (色、明るさ、R、G、B、アルファ) を切り替える。
- 全体の明るさ (露出) を変えて、暗い部分や明るい部分を確かめる。
- ガンマや白黒の反転で、見え方を変える。
- 拡大縮小のときの補間を選ぶ。
- 画面の色を合わせる設定 (色管理) を知る。

## チャネルを切り替える

**表示 > チャンネル** (View > Channel) で、全セルを同時に切り替えます。1 つのセルだけを変えるときは、セルを右クリックして **チャンネル** (Channel) から選びます。

```{list-table}
:header-rows: 1
:widths: 20 80

* - 項目
  - 見え方
* - カラー (Color)
  - 通常のカラー表示
* - グレー (Gray)
  - 明るさ (輝度) だけの白黒表示
* - 赤 / 緑 / 青 (Red / Green / Blue)
  - その色の強さだけを、白黒で表示
* - アルファ (Alpha)
  - 透明度を、白黒で表示 (白が不透明)
```

R、G、B を 1 つずつ見ると、色の乗り方の違いが分かりやすくなります。

## 明るさ (露出) を変える

ツールバーの太陽のボタンを押すと、露出の調整が開きます。スライダーか数値で、**EV** (露出の段数) を指定します。
EV を 1 上げると、明るさが 2 倍になります。**表示 > 露出を上げる** (View > Increase Exposure) / **露出を下げる** (Decrease Exposure)
(<kbd>]</kbd> / <kbd>[</kbd>) でも、段階的に変えられます。<kbd>\</kbd> キーで、0 に戻ります。

0 以外にすると、ボタンに値 (`1.5 EV` など) が出ます。

```{tip}
EXR や HDR のような、1.0 を超える明るい値を持つ画像は、そのままでは白く飛んで見えます。
露出を下げると、明るい部分の濃淡が見えてきます。暗い部分は、露出を上げて確かめます。
```

## ガンマと反転

セルを右クリックして、そのセルの見え方を変えます。

- **ガンマ** (Gamma): 中間の明るさを変える。`1.00` が元のままです。**カスタム...** (Custom...) で、任意の値 (0.01 から 10) を指定できます。
- **反転** (Invert): 白黒を反転する。**表示 > すべてのセルを反転** (View > Invert All Cells) で、全セルを一度に反転できます。

セルごとの調整を元に戻すには、**セルの表示を戻す** (Reset Cell Display) を選びます (倍率、ガンマ、回転、反転が戻ります)。

## 透過部分の背景

**設定 > アプリ設定…** (Settings > App Settings...) の **表示・再生** (Display and playback) にある **透過部分の背景** (Transparency background) で、
**単色** (Solid color) と **市松模様** (Checkerboard) を切り替えます。
**背景の色** (Background colors) の色見本を押すと、単色の色、または市松模様の 2 色をそれぞれ選べます。
方式を切り替えても、それぞれの色は保持されます。

セルの画像の外側にある背景領域を右クリックし、**透過部分の背景** (Transparency background) からも切り替えられます。
現在の方式にチェックが付き、選ぶと全セルとルーペへすぐに反映されて保存されます。色の変更は設定画面で行います。

```{figure} _static/images/transparency-background-menu.png
:alt: 右クリックメニューから透過部分の背景を切り替える

現在の方式にチェックが付いた、透過部分の背景のメニュー。
```

**OK** を押すと、全セルとルーペへすぐに反映され、次回の起動後も使われます。キャンセルすると変更は反映されません。
画像の外側の暗い余白は変わりません。市松模様の大きさは、画像を拡大・縮小しても一定です。
この背景は表示用で、画素値や解析結果、コピーする画像には含まれません。

## 拡大縮小の補間

メニューバーの「ヘルプ」の左にある **設定 > アプリ設定…** (Settings > App Settings...) を開きます。
ダイアログの左側で **表示・再生** (Display and playback) を選び、補間の方法を指定します。

```{figure} _static/images/settings.png
:alt: 設定のダイアログ
:width: 640px

設定のダイアログ。左側で **全般** (General)、**表示・再生** (Display and playback)、**色管理** (Color management)、**キャッシュ** (Cache) を選び、右側で編集します。
```

ページを移動しても編集内容は保持されます。**OK** で全ページの変更をまとめて適用し、**キャンセル** または閉じる操作では破棄します。
右側の内容が収まらない場合はスクロールできます。OK・キャンセルのボタンは常に下部に表示されます。

項目やそのラベルにマウスを合わせると、ページ下部の **説明** (Information) に項目名と説明を表示します。
キーボードで項目にフォーカスを移しても表示されます。マウスが離れても最後の説明が残り、長い説明は欄の中でスクロールできます。
再起動が必要な設定、これから開くファイルに適用する設定、項目を選べない理由は、その項目の近くにも表示されます。


```{list-table}
:header-rows: 1
:widths: 25 75

* - 設定
  - 内容
* - 拡大時の補間 (Magnify filter)
  - 拡大するときの方法。**最近傍** (Nearest) は、画素を四角いまま表示します (既定)。画素の値を確かめるのに向いています。
    **なめらか** (Smooth) は、滑らかに補間します。
* - 縮小時の補間 (Minify filter)
  - 縮小するときの方法。**平均** (Area) は、周りの画素の平均を使います (既定)。動かしてもちらつきません。
    **最近傍** は、画素を間引くので、ちらつきますが、元の値がそのまま見えます。
```

## 画面の色を合わせる (色管理)

Heiran は、画像に埋め込まれた色の情報 (ICC プロファイル) を読んで、お使いのディスプレイの色へ変換して表示します。
プロファイルのない画像は、sRGB の画像として扱います。浮動小数の画像 (EXR など) は、リニアな値として扱います。

**設定 > アプリ設定…** の **色管理** (Color management) で、次を選べます。

```{list-table}
:header-rows: 1
:widths: 25 75

* - 設定
  - 内容
* - 表示のプロファイル (Display profile)
  - 変換先。**表示のプロファイル** (Display profile) はディスプレイに割り当てられたもの、`sRGB` は常に sRGB (ほかのパソコンと見え方を合わせたいとき)、
    **ICC ファイル** (ICC file) は指定したファイル
* - 変換の方法 (Rendering intent)
  - 色域の外の色の扱い。通常は **相対的な色度を保持** (Relative colorimetric) のままで構いません
* - 黒点の補正 (Black point compensation)
  - 最も暗い色を、ディスプレイの最も暗い色に合わせる
* - 解析の値 (Analysis values)
  - 解析で使う値の種類。**ファイルの値のまま** (Source values) はファイルに入っている値のまま、**線形光** (Linear light) は光の量に直した値
```

CMYK の画像 (PSD、TIFF) も、プロファイルを使って、画面の色へ変換します。

## 表示の設定

**設定 > アプリ設定…** には、ほかにも次の項目があります。
画素値の単位、ページ切り替え、セルの境目は **表示・再生**、配色と言語は **全般** にあります。

- **画素値の単位** (Pixel value unit): 画素の値の単位 (`0 - 255` か `0.0 - 1.0`)。**表示 > 画素値の単位** (View > Pixel Value Unit) と同じです。
- **ページ切り替え** (Page change): ページを替えたときに、画像をセルへ収め直す。**表示 > ページ切り替え時にフィット** (View > Fit on Page Change) (<kbd>Shift</kbd> + <kbd>F</kbd>) と同じです。
- **セルの境目** (Cell borders): セルの境目を暗い線で区切る。
- **配色** (Color theme): 画面の配色 (**システムに従う** (System)、**ライト** (Light)、**ダーク** (Dark))。画像の背景は、どの配色でも同じ暗い色のままです。
- **言語** (Language): 画面の言語 (**システムに従う**、`English`、`日本語`)。次に起動したときから変わります。
