# テスト観点

同期表示の状態、座標変換、画素値とルーペについて、**確かめるべき観点**を定める。仕様は
[表示状態仕様](./表示状態仕様.md) と [座標と画素値の仕様](./座標と画素値の仕様.md) にある。
テストの書き方と、`CMakeLists.txt` への登録手順は [AGENTS.md](../AGENTS.md) にある。

## インストーラーの翻訳

- `tests/InstallerLocalizationTests.cmake` で、旧版削除の確認と失敗メッセージが翻訳リソースを参照し、
  関連付け項目の名前・説明も言語ごとに切り替わる設定であることを確認する。
- `resources/nsis/preview.nsi` で、日本語と英語の確認ダイアログ、関連付け項目の名前・説明の表示を確認する。
  確認の選択肢は、実際のファイルの削除やレジストリへの書き込みを伴わずに試せる。
- `tests/InstallerAssociationSelectionTests.cmake` で、全拡張子が既定で選択されること、一部を外すとその拡張子だけ登録対象から外れること、全解除を確認する。
  本番と共通の選択判定マクロを使い、レジストリへの書き込みは行わない。プレビューではカテゴリの一括選択と、容量を表示しないことも確認する。

## 目的

- `GlobalViewState` と `CellViewState` の更新の責務が崩れないこと。
- 同期の ON / OFF、ページの切り替え、ズーム、パンの組み合わせで、意図しない状態の破壊が起きないこと。
- 回転、反転、EXIF の向き、倍率、オフセットを組み合わせても、表示座標と画像座標の対応が崩れないこと。

## 前提

- ズームは、`sync_enabled` に関わらず `GlobalViewState` を更新する。
- パンは、同期有効のセルなら `GlobalViewState`、無効のセルなら対象のセルの `CellViewState` を更新する。
- ページ番号は全セルで共有する。`offset_delta` は、同期を有効に戻しても保持する。
- 画像座標は左上原点で、画素の取得の丸めは `floor`。選択矩形は半開区間 `[x0, x1)`, `[y0, y1)`。

## 1. 同期の状態遷移

ケースは、`同期 Case 1`、`座標変換 Case 9`、`画素値 Case 15` のように、節の名前と番号で参照する (`tests/` のコメントが、この名前で参照している)。

| # | ケース | 期待 |
| --- | --- | --- |
| 1 | 同期有効のセルをパン (ほかのセルに既存の `offset_delta` がある) | `base_offset` だけが更新される。対象のセルの `offset_delta` は変わらない。同期無効のセルの見た目は変わらない |
| 2 | 同期無効のセルをパン | 対象のセルの `offset_delta` だけが更新される。`GlobalViewState` と、ほかのセルの見た目は変わらない |
| 3 | 同期有効のセルをズーム | `base_scale` と、固定点を保つための `base_offset` が更新される。全セルの `final_scale` が変わる。各セルの `offset_delta` は保持される |
| 4 | 同期無効のセルをズーム | `base_scale` と `base_offset` が更新され、結果が全セルへ反映される。対象のセルの `offset_delta` は、ズームだけでは直接更新されない |
| 5 | 同期を無効にする | `offset_delta = final_offset - base_offset` が設定される。見た目は、切り替えの前後で変わらない |
| 6 | 同期を有効に戻す | `offset_delta` は保持され、見た目は変わらない。以後のパンは、同期有効として扱われる |
| 7 | ページを切り替える | `current_page` だけが更新される。各セルの `offset_delta` と `scale` は保持される。画像のないセルは空欄になる |

### 例外のケース

| # | ケース | 期待 |
| --- | --- | --- |
| 8 | 同期無効のセルに大きな `offset_delta` がある状態で、ページを切り替える | `offset_delta` は保持され、新しいページへ、同じ画像座標の基準で適用される。ページが無ければ空欄になる |
| 9 | 画像の大きさの異なるセルでズームする | 固定点は、操作したセルの基準で計算する。ほかのセルには、同じ `base_scale` と `base_offset` が適用され、左上基準の比較が保たれる |
| 10 | 空欄のセルを含む状態でズームする | `GlobalViewState` は更新できる。画像のあるセルだけ、見た目が更新される。空欄のセルで、例外や不正な値が出ない |
| 11 | 読み込みに失敗したセルを含む状態でパンする | ほかのセルのパンは続けられる。失敗したセルの表示状態の保持と、操作できない状態が矛盾しない |
| 12 | 選択範囲があるときに、ページを切り替える | `selection_rect` は保持される。新しいページに有効な画素がなければ、解析側では「対象なし」。表示側は、範囲外の部分を描かない |

## 2. 座標変換

画像の大きさ 4 x 3 などの小さい画像で、四隅の対応を確かめる。どれも、**逆変換で元へ戻る**ことを併せて確かめる。

| # | ケース | 期待 |
| --- | --- | --- |
| 1 | 変換なし (rotation 0、flip なし、scale 1.0、offset (0, 0)) | `(x, y)` が、そのまま `(view_x, view_y)` へ写る |
| 2 | オフセットのみ (offset (10, 20)) | `image(10, 20)` が `view(0, 0)`、`image(11, 20)` が `view(1, 0)` に対応する |
| 3 | 倍率のみ (scale 2.0) | `image(1, 1)` が `view(2, 2)` に対応する。逆変換して `floor` しても、期待する画素へ戻る |
| 4 | 90 度回転 (4 x 3) | 四隅の対応が、回転後の大きさ (3 x 4) と整合する (範囲外にならない) |
| 5 | 180 度回転 | `image(0, 0)` が `rotated(width - 1, height - 1)`、その逆も成り立つ |
| 6 | 270 度回転 | 90 度回転と逆向きの対応になる |
| 7 | 左右反転 | `image(0, y)` が右端へ、`image(width - 1, y)` が左端へ対応する |
| 8 | 上下反転 | `image(x, 0)` が下端へ、`image(x, height - 1)` が上端へ対応する |
| 9 | 90 度回転 + 左右反転 | 回転の後の座標に、左右反転が適用される。先に反転してから回転した結果とは、異なる |
| 10 | EXIF の向きを適用 (90 度相当、利用者の回転 0) | EXIF だけで回転した表示になる |
| 11 | EXIF の向きを無視 | 生の画素配列どおりの向きで表示される |
| 12 | EXIF + 利用者の回転 180 度 | EXIF を先に適用し、その後に利用者の回転が適用される |
| 13 | 同期有効のセルのズーム | マウスの位置に対応する画像座標が、ズームの前後で、同じ画面位置に残る |
| 14 | 同期無効のセルのズーム | 操作したセルが何であれ、ズームは全セルへ反映される。固定点が保たれる。`sync_enabled` は、ズームの反映の可否に影響しない |
| 15 | 左上から右下へドラッグして選択 | `[x0, x1)`, `[y0, y1)` の半開区間に正規化される |
| 16 | 右下から左上へドラッグして選択 | 逆向きでも、同じ矩形に正規化される |
| 17 | 画像の境界上の選択 | 最後の 1 画素だけを含む矩形で、off-by-one が起きない |

## 3. 画素値とルーペ

| # | ケース | 期待 |
| --- | --- | --- |
| 13 | 画素値の基本の取得 | マウスの位置から逆変換した画像座標の画素値が取れる。取得元は解析用バッファ。参照するのは、回転、反転、EXIF の向きを戻した、元の画像の座標 |
| 14 | 右端と下端の境界 | 右端ちょうど、下端ちょうどの座標は、半開区間として範囲外になる。値は「範囲外」になり、ルーペも「対象なし」かクリアの状態になる |
| 15 | 空欄のセルと読み込みに失敗したセル | 空欄では「画像なし」、失敗では「読込失敗」と出る。ほかのセルの状態に影響しない |
| 16 | パンの後の再計算 | 同じ画面座標でも、パンの後は、新しい画像座標の値へ更新される。ルーペの中心も、新しい元の画素へ追従する |
| 17 | ズームの後のルーペの追従 | ズームの前後で、固定点に対応する元の画素が維持される。ルーペは、ズーム倍率ではなく、元の画素の中心に追従する。同期無効のセルでも、全セル共通のズームと矛盾しない |
| 18 | ページ切り替えのときのルーペの更新 | 同じマウスの位置に画像がある場合だけ、切り替え先の値とルーペへ更新される。無ければ「画像なし」か対象なし |
| 19 | 回転、反転、EXIF つきの画像の画素値 | 変換後の表示位置から逆変換しても、常に、元の画像座標に対応する画素が取れる (座標変換の結果と整合する) |

## 自動テストの優先順位

1. 同期のパン (有効 / 無効)、無効のセルのズームが全セルへ反映されること、同期の切り替えで見た目が保たれること、ページの切り替えで
   `offset_delta` と `scale` が保たれること
2. 変換なし、倍率とオフセット、90 度回転、180 度回転、左右反転、回転 + 反転、EXIF の適用の有無、選択矩形の半開区間の正規化
3. 範囲内の画素の基本の取得、右端と下端の半開区間の判定、パンの後の再計算、ズームの固定点での追従、回転と反転を含む逆変換

`LoupeWidgetTests` は、透過画素へ選んだ背景が合成され、画像の外の暗い背景は変わらないことも確認する。

- マウス操作は、`QTest::mousePress` などで、**セル内の描画面** (`findChild<QWidget *>("imageCanvas")`) へ直接送る。ヘッダーと描画面は別のウィジェット。
  ホイールは、`QWheelEvent` を組み立てて送る。
- EXIF の向きの見本は、Qt で書き出した JPEG へ、向きだけを持つ最小の APP1 を差し込んで作る (Qt に EXIF を書く手段が無いため)。
- **ズームとパンのテストは、「変わらないこと」だけを見ない** (イベントが届いていないと素通りする)。固定点の座標が保たれることに加えて、固定点から離れた点の
  参照先がずれることを併せて見る。**書いたテストは、実装を壊して、落ちることを確かめる。**
- ズームとパンは `viewChanged` を出さない (この signal は、ページ操作の反映と解析の再計算の契機で、表示変換だけの変更では出さない)。成否をこの signal で見ない。

## 手動の確認

- 2x2 の表示で、1 つのセルだけ同期を無効にしてパンしても、ほかのセルが動かないこと。
- 同じ状態でホイールでズームすると、全セルが拡大縮小すること。
- 同期を無効にしてから有効にしても、セル固有のずれが消えないこと。
- 空欄のセルを含むページでも、ズームやページの移動が破綻しないこと。
