# 解析機能設計

`Heiran` の解析機能 (ヒストグラム、3 次元ヒストグラム、変化グラフ、差分、画像情報) と、共有選択範囲、
解析ウィンドウの運用を定める。判断の経緯は [設計判断.md](./設計判断.md) にある。

## 基本方針

- 解析は**解析用バッファの値**から行い、表示用の画像からは行わない。表示の露出、ガンマ、チャネル表示、白黒反転は、解析の値を変えない。
- 解析は読み取り専用で、解析用バッファを変更しない。
- 解析は、全セルを対象にできる。選択範囲があれば、その範囲だけを集計する。
- 値は、ファイルのまま (`source`、既定) か線形光 (`linear`) から、アプリの設定で選べる。輝度は、色空間から導いた重み
  (sRGB なら 0.2126 / 0.7152 / 0.0722) を、画素値表示、ルーペ、差分、変化グラフで共通に使う。

## 解析ウィンドウの運用

- 解析機能は、機能ごとの独立したウィンドウ (`HistogramWindow`、`Histogram3DWindow`、`DiffWindow`、`ChangeGraphWindow`、
  `ImageInfoWindow`)。再度開くときは、既存のものを再利用する。
- **閉じる操作は、破棄ではなく非表示。** 隠れている間は計算せず、届いた分は保持して、次に開いたときに 1 度だけ計算する。
  この規則は `AnalysisWindowBase` に 1 つだけ置く。表題には、ページ番号を付ける。
- 解析の対象は、`ViewerGridWidget` が全セルの `AnalysisImage` (表示用の画像、選択範囲、解析用バッファの読み出し、ラベル、
  ファイルのパス) の並びとして渡す。ウィンドウが自分で集計する。集計は、純粋な関数 (`HistogramSeriesBuilder`、
  `ChangeGraphSeriesBuilder`、`renderDiff` など) に分け、テストできる形にする。
- 解析の対象にするセルは、画像のあるセル全部。空欄と読み込みに失敗したセルだけ、自動で除外する。個別の ON/OFF 切り替え UI は
  持たない (全セルの解析で、視認性や計算時間の問題が確認されたら検討する)。
- 全セルが解析できないときは、結果を消して、状態のメッセージを出す。セッションを閉じたときは、グラフを消して
  「解析対象がありません」と出す。
- 再計算の契機は、ページの変更、選択範囲の変更、チャネルや解析値の空間の変更、読み込みの完了。**パンとズームでは再計算しない**
  (解析の対象の画像座標範囲が変わらない)。

## 共有選択範囲

- 選択範囲は全セルで共有する。**選択を始めたセルを基準にした画像座標の半開区間**で持ち、他のセルへは、各セルの
  `FinalViewState` から再投影する (回転、反転、EXIF の向き、倍率が違っても、画面上で同じ場所を指す)。
- 作るのは `Shift` + 左ドラッグ。ドラッグ中は、他のセルにも暫定の矩形を出す。ドラッグの確定で、共有の状態へ反映する。新しい選択は、
  既存の選択を置き換える。解除は `Esc`。複数の矩形や加算の選択は扱わない。
- パンとズームをしても、選択範囲は基準のセルの画像座標で保持し続ける。ページを替えても、座標は保持する。
- 画像の外へはみ出した範囲は、解析のときに各セルの実画像の範囲へクリップする。集計する画素が 0 のセルは、「対象なし」。

## ヒストグラム

- 解析対象のセルごとに、ヒストグラム (R、G、B) を並べる。配置は、ビューアのセルの配置の順に従い、最小のサイズ
  (横 240 px、縦 160 px 程度) を下回るときは、縮めずにスクロールさせる。グラフの見た目は全セルで統一し、差はラベルと並び順で
  表す (線の色で表さない)。各グラフに、セル名、ページ番号、チャネル、全体か選択範囲かを出す。
- **縦軸は、画素数で割った割合。** 軸の上限は、最大の度数ではなく**倍率**で決める (既定は、割合 1.0 が枠いっぱい。倍率 0.1 から
  100 倍)。対数軸は、倍率とは別の操作で、両方を掛けられる。
- **横軸は、全セル共通**で、`0.0` から全セルの実データの最大値まで。最大値の下限は `1.0` (整数画像だけなら、常に `0.0 - 1.0`)。
  最大値の走査は、浮動小数のバッファのときだけ行う。横軸のレンジを調整でき、マウスを乗せると、その位置の値を出す。
  縦軸を固定する設定もある。
- **統計値**: 平均、標準偏差、最小、最大は、ビンではなく**画素の値**から求める。最頻値だけは、ビンから取る。
- ヒストグラム上の横ドラッグで値の区間を選び、全セルで区間内の画素を強調する。既定は R・G・B のいずれかが一致する画素とし、個別のチャネルも指定できる。値の両端を含み、画像上の矩形選択があれば、その内側に絞る。
- 強調範囲は軸の表示範囲と独立した実値で保持する。ページや解析値の設定が変わったら同じ範囲で評価し直す。Esc、強調解除、ヒストグラムウィンドウを閉じる操作で解除する。
- マスクはヒストグラムと共通の解析入力を用いて、ドラッグ確定後にワーカーで作る。ページや選択が変われば古い結果を破棄する。表示座標の 1 ビットマスクを選択範囲の分だけ作り、画像の上へ重ねる。
- 集計は、チャネルごとに平面を 1 つずつ作って畳む (3 つを同時には持たない)。行を帯に分けて並列にする。
- **3 次元ヒストグラム**: 指定した 1 つのセルについて、軸ごとのビン数 (2 から 64) を指定して、RGB の分布を立方体の中の点として出す。
  向きは、ドラッグで回せる。

## 波形モニタ

- 画像の**位置 (列)** と**値**の 2 次元の分布を、セルごとに出す (Analysis > Waveform)。横は、画像の列を、最大 1024 の升目へ割り当て、縦は、値を 256 の升目へ分ける。
  升目の数が、その列、その値の画素の数。R、G、B、輝度の 4 つを、同時に数えるため、表示の切り替え (輝度、RGB の重ね、Parade) で、数え直さない。
- **濃さは、列ごとの密度**で決める (その列の画素が、値の升目へ一様に散らばっていれば 1)。画像の大きさや、列の割り当て方に依らず、見え方が揃う。
  `1 - exp(-0.35 x gain x 密度)` で飽和させる (`Brightness` が倍率)。
- 値は、**解析用バッファの値** (値の空間は、設定の `Analysis values`)。0.0-1.0 の範囲外 (HDR の 1.0 超え、負、NaN) は、端の升目へ収める。
  選択範囲があれば、その範囲だけ。回転と反転は、解析の規則どおり (走査の並びで扱う)。
- 計算は、RGB の平面を 1 回の走査で作り (差分の色差と同じ経路)、行を帯に分けて、帯ごとの升目を作って足し合わせる (並列)。結果は、`AnalysisResultCache` へ取っておく
  (画像と選択範囲の同一性が鍵。表示の調整は鍵に入れない)。

## ベクトルスコープ

- 色の分布を、**色差 (Cb が横、Cr が縦、上が +Cr) の面**へ数える (Analysis > Vectorscope)。256 x 256 の升目。Cb、Cr は、輝度の重みから導く
  (`Cb = (B - Y) / (2 (1 - wB))`、`Cr = (R - Y) / (2 (1 - wR))`。範囲は -0.5 から 0.5)。輝度の重みは、元の色空間から求めた値 (画素値表示と同じ)。
- 升目の色は、その升目の色差を、一定の輝度で RGB へ戻した色。濃さは、対数 (まばらな升目も見える)。1 つの升目が小さいため、上下左右へ弱くにじませる。
- 目盛り: 軸、輪 (色差の大きさ 0.25 と 0.5)、**肌の色の線** (I 軸。+Cb の軸から約 123 度)、75% の R、Y、G、C、B、M の目標。目標の位置は、輝度の重みから求める
  (色空間によって、位置が変わる)。
- 計算の方法と、取っておく規則は、波形モニタと同じ。

## 変化グラフ

- 縦に平均して横方向の変化、または横に平均して縦方向の変化を、プロットする。
- 既定は、セルごとの図を縦に並べる。セルを重ねる表示もあり、重ねるときは、チャネルを輝度に固定する。
- 縦軸の上限は、整数画像では 1.0 で固定 (浮動小数画像だけ、実データの最大値まで)。横軸は画像座標で、選択範囲があれば、その左端
  (または上端) から。平均の和は `double` で持つ。

## 差分

画像一覧の 2 枚選択と、外部ツールからの `heiran --diff [--left-title title] [--right-title title] left right` は同じ専用画面を開く。
左に比較設定、右に同期した元画像 2 枚を表示する。横並びでは左右の画像に差分を重ねられる。
右側全体で基準画像を強調する表示と、左右の画像を交互に表示する点滅も選べる。
強調表示では、1 枚と横並びのどちらでも、強調色だけを 0.5 秒ごとに表示・非表示にできる。
左右の強調は同じタイマーで切り替える。閾値が変わると差分マスクを更新し、表示や点滅の切り替えでは再計算しない。
横並びでは、差の場をグレーで表示する差分マップを 3 枚目に追加できる。輝度・RGB 最大差は絶対値の 0–255、色差は ΔE 10、構造の差は 1 − SSIM の 1 を白の目安とする。
画素値で比較する場合は、比較方式で求めた差と 0–255 に換算したアルファの差の大きい方を使う。片側だけの画素は白で示す。比較条件が同じ間は差の場とマップを再利用する。
マップは比較座標で表示し、パン・ズーム・差分移動が連動する。強調を点滅させている間もマップを表示する。
移動先の枠と、その領域内で強調対象になった画素は赤で示す。赤い強調マスクは移動先と元のマスクが同じ間は使い回す。
マップの明るさは 1～32 倍で、表示用のパレットだけを変更する。凡例に黒と白が示す値を表示する。マップを再表示しても、比較条件が同じ間は倍率を適用済みの表示用画像を使い回す。
ブロックサイズは 1–128 px とし、既定の 1 px は画素単位の強調を使う。2 px 以上では左上を原点とするブロックに区切り、
差分を 1 画素でも含むブロックを強調と差分移動の対象にする。画素数は実際の差分だけを数える。
透明度は元画像に重ねる強調色に適用する。ブロックサイズや透明度を変えても差の場は再計算しない。
閾値・ブロックサイズ・強調の透明度はスライダーと数値入力を連動させ、ドラッグ中も表示を更新する。差の場を使い回せる間は前の表示を保ち、描画の完了順に更新する。処理中に操作が続く場合は次の描画に最新の設定を使う。
同期した拡大率は数値でも変更でき、ホイール操作やフィット後は現在の倍率を表示する。
強調・件数・移動先の判定を共通にする。輝度・色差・SSIM には選択中の閾値を使い、アルファ値の差と、左上をそろえたときの片側だけの領域も数える。
小さな色の差だけを閾値で除外しつつ、透明度やキャンバス変更を見つけるため。強調対象外の画素は各画像をそのまま表示する。
左上をそろえる場合は同じ原点からマスクを表示する。画像寸法をそろえて比較する場合は、比較座標のマスクを各画像の表示寸法に合わせて重ねる。
専用画面では既定で、左右ともアルファ値が 0 の画素の RGB 差を、強調・件数・移動先と先頭画像の画素の一致判定から外す。
表示に寄与しない RGB が拡大縮小や SSIM の近傍に影響するのを防ぐため、完全透明な画素の RGB と輝度を中立値にしてから計算する。
設定は比較画面内で画像の組を切り替えても引き継ぎ、元データの RGB を確かめる場合はオフにできる。
透明度の比較方法には、画素値、白背景への合成、黒背景への合成を用意する。既定は画素値。背景を選ぶと、左右を表示用の
sRGB 8bit で合成してから輝度・色差・SSIM を求める。選択した背景で見える差を確認するため、強調・件数・移動先は合成結果で判定し、
アルファや片側だけの領域は合成色に差が出たときに数える。横並びと点滅にも比較背景を適用し、原画像の一致判定を別記する。
高精度データの変更を調べる場合は画素値で比較する。比較方法の既定は RGB 成分の最大差とする。設定に基づく差分件数と復号した画素の一致は別々に表示する。
閾値の近くには比較方法に応じて判定の向きと尺度を表示する。フォルダ比較で画像の組が変わっても表示方式を維持し、点滅は新しい組の準備後に開始する。
RGB差 (`rgb-max`) は画素ごとに R・G・B の絶対差の最大値を 0–255 の尺度で求める。輝度が近い配色変更を成分の差で見つけるために使う。
専用画面の差の場・描画画像・差分領域は `ComparisonDiffController` がバックグラウンドで作る。
処理中も設定や次の画像を選べるよう、待ち行列は最新の 1 件に絞り、画像や設定が変わった結果は破棄する。
前後の差分は F7／F8、前後の変更ファイルは Ctrl+F7／Ctrl+F8 で移動する。
通常の差分セルと差分ウィンドウは、表示モードに応じて差の大きさを色や明るさで示す。
グリッドの差分計算とレンダラーを共用する。指定された 2 ファイルをその順序で開き、アニメーションは停止状態で始める。
Git クライアントの一時ファイルを扱えるよう、専用画面の画像は最近開いた画像への登録を省く。
アプリ内では、メインウィンドウ内で比較のページへ切り替える。同じウィンドウの位置と最大化状態を使い、元のビューアーを保持したままメニューやドックを一時的に隠す。
「比較終了」または Escape で元のレイアウト・ページ・一覧の選択へ戻る。外部ツールから `--diff` で起動した場合は、同じ比較ウィジェットを独立したウィンドウに表示する。

「ファイル > 比較…」と起動案内の「比較…」からは、同じ対象選択ダイアログを開く。上下に並ぶ 2 つのグループから対象を指定する。各グループのパス欄は横幅いっぱいに取り、
パスを入力・貼り付けるか、その下のボタンからファイルまたはフォルダを選ぶ。
ドロップしたローカルパスは 1 件なら対象グループの欄に入り、2 件ならドラッグ元が渡した順に両方の欄に入る。
パス欄の地色と枠線は配色ごとに調整し、操作中の欄には強調色の太い枠線を付ける。
1 番目を左、2 番目を右に表示する。画像ファイル 2 つは画像差分、フォルダ 2 つはフォルダ比較を開く。
存在しないパスやファイルとフォルダが混在した指定は開始前に案内する。
比較では、配下の相対パス（大文字・小文字を含む）をキーに画像とその他のファイルを照合する。
Git 管理情報とディレクトリリンクは探索対象から外す。照合とバイト列の比較はキャンセルできるバックグラウンド処理で走らせる。
片側の走査に失敗した範囲は、反対側の同じ相対パスが存在するか不明として「読み込み不可」にする。
画素の一致は選択した画像組について、復号した先頭画像の RGBA を別途比較する。色空間が異なる場合はそれも表示する。
この方式では、ファイル全件の画像を復号せず、変更ファイルを巡る操作と画像内の差分を巡る操作を分けられる。
画像以外の組は同じ一覧から設定済みの外部差分ビューアーへ左・右のファイルパスを渡す。テキストの確認が同じ画面で頻繁に行われるようになったら内蔵表示を見直す。

- 差は、**比べる側 - 基準** の輝度。数値指標として、最大の絶対差、平均の絶対差、符号付きの平均 (正なら比べる側が明るい)、RMSE、
  PSNR、閾値を超えた画素の数と割合を出す。
- 計算のモード: `absolute`、`signed`、`binary`、`delta-e` (色差)。見せ方: `grayscale`、`signed-color` (正が赤、負が青)、`overlay` (基準の画像に重ねる)。
  倍率 (`gain`)、閾値 (`threshold`、輝度の 0-255)、自動の範囲合わせ (`auto_range`、差の最大を 255 に合わせる) を持つ。
- **色差 (`delta-e`)**: 輝度ではなく、RGB 全体の色の違いを CIEDE2000 (ΔE00) で測る。輝度がほぼ同じで色相だけが違う組を拾える。
  Lab は**線形光**で測る (値の空間の設定に関わらず線形へ戻す)。XYZ への行列は基準の画像の色空間から求める。見せ方は、グレーと重ね合わせ
  (符号が無いため、符号付きの色は、グレーと同じ)。閾値は ΔE の単位 (切り替えたとき、閾値が既定のままなら、輝度の 8 と ΔE の 2.3 を
  入れ替える)。自動の範囲合わせを切ると、ΔE 10 が最も明るい階調。指標は、ΔE の最大、平均、閾値を超えた画素の割合 (RMSE と PSNR は、
  輝度のモードだけ)。費用は、輝度の差より大きい ([設計判断.md](./設計判断.md#解析機能))。
- **構造的類似度 (`ssim`)**: 輝度の局所の構造 (明るさ、コントラスト、相関) の違いを、SSIM (Wang ら 2004) で測る。標準の窓 (11 x 11 のガウス窓、σ = 1.5)
  と値の幅 255 で、輝度の平面から求める (1 が同一)。見せるのは **1 - SSIM** (似ていないほど明るい。自動の範囲合わせで、最も似ていない所が最も明るい)。
  指標は、SSIM の平均と最小、閾値を下回った画素の割合。窓が画像の外へ出る端は、端の画素を延ばして補うため、**指標は、窓がすべて画像の中に入る内側
  (端から 5 画素を除いた範囲) だけで数える** (参照の実装と同じ範囲。参照とは、端の補い方が違うだけで、内側は一致する)。画像が 11 画素未満なら、全体を数える。
  輝度だけで測る (色の違いは、`delta-e` で見る)。16bit や浮動小数の画像は、値の幅 255 のまま (1.0 を 255 へ写した輝度) で測る。
- **ワイプ (`wipe`)**: 差ではなく、基準 (左 / 上) と比べる側 (右 / 下) を、境目で切って、つなぎ合わせる。差分のセルと同じ仕組み (`DiffMode::Wipe`) で、
  基準と比べる側の選び方、大きさの合わせ方 (`size_match`)、`.hrn` (`wipe_direction`、`wipe_position`)、作り直しの規則を共有する。表示用の 8bit の絵
  から、行ごとの複写で作る (4K でも数 ms)。境目の位置は、画像の座標 (拡大と移動に追従する)。境目の線は、セルの上の部品で、ドラッグで動かす (回転や
  反転があるセルでは、向きが合わないため出さない。位置は、帯のポップアップの `Position` で指定する)。指標は無い。
- **差分は、グリッドのセルとして並べて見せる。** 差分のセルは通常のセルと同じに、ズームとパンの同期と画素値の表示を受け、
  解析ウィンドウの対象にもなる。
  - 空きセルへ「基準のセル」と「比べるセル」の差分を出す方式と、画像のあるセルを、基準のセルとの差分に置き換える方式がある。
    Analysis > Diff Cell (空きが無ければ格子を広げる)、セルの右クリックの Show Difference vs で始める。
  - 求め方、差分への移動、点滅、数値指標は、画像の面の**下端に重ねる帯**に出し、**マウスが乗っている間だけ**見せる (入力の途中は出したまま)。そのほかの設定
    (基準と比べる側、見せ方、倍率、閾値、自動の範囲、大きさの合わせ方) は、帯の**歯車のボタンで開くポップアップ**に置く。指標が帯の幅を超えるときは、
    省略記号で切る (全文はツールチップ)。比べているセルは、セルの題が示す。
  - 指定は `.hrn` の `cells[].diff` へ保存する ([設定ファイル仕様.md](./設定ファイル仕様.md))。
  - 差分は、他のセルが見せている画像から作る。各セルの回転と反転は掛けず、差分のセルを元にもしない。入力か設定が変わったときだけ作り直す。
  - 差分のヘッダーは「Diff: Cell 2 - Cell 1」と大きさを出す。
  - 前後の差分への移動は、指標と同じ閾値を差の場に適用する。該当画素を含む 16×16 画素の区画を辺でつないでまとめ、
    各まとまりの該当画素を囲む矩形を上から下へ、同じ高さでは左から右へ巡る。微小な差が点在しても、1 画素ずつ巡らずに済む。
    矩形は最初に移動したときに求め、入力・差の種類・閾値が変わるまで再利用する。
    移動は通常のパンと同じように同期し、差分セルには現在の矩形を描く。解析用の選択範囲とは独立する。
  - 点滅は 2 枚の表示用画像を差分と同じ大きさの指定でそろえ、差分セルの同じ位置で 500 ms ごとに切り替える。
    既存の GPU テクスチャキャッシュを使う。点滅はその場で使う表示操作とし、解析には差分画像を使う。
    比較元・ページ・大きさの指定が変わったときは停止する。細かい差が散在して移動しづらい事例があれば、区画の大きさや結合方法を見直す。
- **大きさの違う画像** (`size_match`): 既定の `overlap` は、**左上をそろえて、重なる部分だけを比べる** (はみ出した部分は、絵にも指標にも入らない)。
  `base` / `target` / `larger` は、もう一方を、基準 / 比べる側 / 面積の大きいほうの大きさへ合わせて比べる (縮小は元の画素の重なりでの
  面積平均、拡大は線形補間。輝度の平面で行うので、元の精度のまま)。
- `DiffWindow` (Analysis > Diff Window) は、**選択範囲の差分**に使う。選択範囲があるときは、同じ大きさの範囲どうしを比べる。計算は共通の
  `renderDiff`。

## 画像情報

- View > Image Info (I キー) で、ファイル、画素の形式、色空間、EXIF などのメタデータを、セルを列にして並べる。セルの間で値が違う行は
  強調し、違う行だけに絞れる。メタデータは自前で読む (`ExifReader`、`ImageMetadata`)。

## 結果のキャッシュ

- ヒストグラムと変化グラフは、`AnalysisResultCache` が結果を取っておく (件数の上限は 64)。ページを行き来するたびに数え直さない。
- 鍵は**画素データの同一性** (`QImage::cacheKey()`、解析用バッファの番地、バイト数)、回転と反転、選択範囲、横軸の上限。
  ページの番号やセル ID は鍵にしない (同じ画像を別のセルで開いたとき、取り違える)。表示チャネルや露出は鍵に入れない (集計は解析用バッファを
  直接読む)。ラベルは、取り出すときに入れ直す。

## 性能の方針

- 全画素を走査する解析は、画素ごとに型や座標の写しを判定せず、**走査の外へ出して、平面を作ってから畳む**。行を帯に分けて並列にする。
- **GPU による集計、SIMD の手書き、事前計算した積算ヒストグラム**は採らない (自動ベクトル化で足り、GPU は結果の読み戻しで差が出ない)。
- 手を入れる前に、内訳を測る。数字は [設計判断.md](./設計判断.md#解析機能) にある。
