# お気に入り

## マークと保存

- 画像ファイルの絶対パスを単位に、★の ON/OFF を保存する。Windows ではパスの大文字・小文字を区別しない。
- 操作対象セルの画像は **画像 > お気に入り > お気に入り**、`B`、ツールバーから付け外しできる。
  セルの右クリックでは、そのセルの画像を対象にする。
- 画像一覧で複数選択し、「お気に入り登録」「お気に入り解除」で選択ファイルの状態をそろえる。
  表示中の各行の代表ファイルを対象とし、未選択ファイルは変更しない。登録済み・未登録が混在していても反転せず指定した状態にする。
  件数に比較表示の 16 枚上限は適用しない。重複を除き、ロック・保存・絞り込み更新をそれぞれ一度で行う。
- マークしたセルには、ヘッダーの表示状態にかかわらず画像領域の右上に★を表示する。
- 保存先は `infra::userDataDirectory()` の `favorites.json`。
  通常の Windows では `%LOCALAPPDATA%/Heiran/favorites.json`。
- 元画像、ファイル名、画像フォルダー、`.hrn` は変更しない。マークや表示の絞り込みでセッションを未保存扱いにしない。
- パスが同じなら、再起動や別のセッションでもマークを再利用する。外部で移動・改名したファイルは新しいパスとして扱う。
  存在しなくなったパスのマークは保持し、同じパスへファイルを戻した場合に再利用できる。

ファイル形式は次の JSON。保存時にキーを並べ、同じパスは重複させない。

```json
{"version": 1, "files": ["e:/images/image001.png"]}
```

更新時にはロックを取得して最新のファイルを読み直し、他のウィンドウの変更と合成する。
`QSaveFile` で置き換え、読み取り・構文・バージョン・書き込みの失敗時は以前のファイルを上書きしない。
保存できなければ利用者へ知らせ、画面上のマークを保存できたものとして扱わない。

## 候補だけの表示

- **お気に入りのみ表示** (`Ctrl+Shift+B`) を有効にすると、表示中のセルのいずれかにお気に入り画像があるページだけを対象にする。
- 各画像セットの一覧を個別に詰め直さず、元のページ番号・ページオフセット・同期比較の対応を維持する。
  矢印キー、ボタン、Alt + ホイール、Home / End、ページ選択、サムネイル選択に同じ絞り込みを適用する。
- 絞り込みの開始やマーク解除で現在ページが対象外になったら、その次の候補へ移る。次がなければ最後の候補へ移る。
  候補がゼロ件なら画像を空表示にし、マーク操作を無効にする。絞り込みの解除は引き続きできる。
- 新しく画像やセッションを開くと、全画像を見られる状態へ戻す。絞り込みは `.hrn` やアプリ設定へ保存しない。

## 一括コピー

- **お気に入りをコピー…** は、現在の可視セルが参照する画像セットに含まれるお気に入りを対象にする。
  開いていない画像セットや別フォルダーだけのマークは含めず、同じファイルは一度だけコピーする。
- 画像のバイト列をそのままコピーする。再圧縮や画素・メタデータの変更は行わない。
- 同名ファイルがあれば `名前 (2).拡張子` 以降の空いている名前を使い、既存ファイルを上書きしない。
  元と同じパスへのコピーはスキップする。
- 別スレッドでコピーし、UI を処理可能に保つ。キャンセル時は完了済みのコピーを残し、途中の一時ファイルは取り除く。
  完了数・スキップ数・失敗数を知らせ、詳細からコピー先や失敗したパスを確認できる。
