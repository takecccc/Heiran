# エラー処理仕様

`Heiran` の、読み込みと保存の失敗の扱いと、セルの状態の表示を定める。設定ファイルの検証の規則は
[設定ファイル仕様](./設定ファイル仕様.md#検証と問題の報告) にある。

## 基本の方針

- **アプリは、失敗しても閉じない。** 読み込みに失敗しても、空のセッションを出したウィンドウを残す (ウィンドウごと閉じると、別のファイルを
  開き直す導線が無くなる)。
- 個別の画像の読み込みの失敗は、セッション全体の失敗にせず、そのセルだけの表示にする。
- 部分的に読み込んで続けられるのは、次の場合だけ。それ以外の設定の解釈の失敗では、壊れたセッションを残したまま続けない。
  - グロブが 0 件
  - 個別の画像の読み込みの失敗
  - ページ数の不一致

## `.hrn` の読み込みの失敗

構文エラー、必須キーの欠落、型の不一致、`format_version` の不正は、読み込みの失敗として扱い、エラーのダイアログを出す。
(範囲外の値や、存在しない参照など、既定値へ読み替えられるものは、警告で続行する。)

- 起動時に失敗したら、空のメインウィンドウを開いたまま、ダイアログを出す。
- ダイアログから、次の操作へ進める: `別の .hrn を開く`、`最近使った .hrn を開く`、`閉じる`。
- 警告だけで読み込めたときは、閉じる操作だけでよい。

### 最近使った `.hrn`

- アプリ全体の設定 (`QSettings`) に持つ。件数は 10 件程度。新しく開いたものは先頭へ移し、同じパスは重複させずに位置だけ更新する。
- 存在しないファイルが一覧に残ってもよい。選んだときに、その場で、読み込みの失敗を知らせる。
- ファイル名とフルパスを区別して見られる。ファイル名が重複するときは、親のディレクトリも併記する。
- 失敗のダイアログと、通常のメニューの、どちらからも同じ一覧を開ける。

## ダイアログの書式

読み込みと保存の失敗は、次の 3 部構成で統一して表示する。保存の失敗も、同じ経路で報告する。

1. **要約**: 失敗の内容 (何が起きたか)、対象 (どのファイルか)、次の操作 (利用者が取れる行動) の順に、短く。問題の件数も含める。
2. **詳細の一覧**: 設定の項目ごとの問題を、`Error` / `Warning`、位置、内容の形で並べる。検出した順。上限で打ち切ったときは、その旨を末尾に付ける
   (`他 N 件の問題があります`)。
3. **固定の操作**: 常に「閉じる」を出す。読み込みを続けられなかったときは、別のファイルを開く導線も出す。スクロールの位置に依存しないよう、
   ダイアログの下部に固定する。

文面の方針:

- 原因は、内部の例外の名前ではなく、**利用者が直せる説明**にする。可能なら、期待した値と実際の値を示す。
- 見出しは短く統一する。例: `設定ファイルを開けませんでした`、`画像を読み込めませんでした`。
- 位置は、`cells[5].image` のように、項目が分かる形で示す。
- 同じ原因から出る二次的なエラーは、重複して出さず、原因の側を優先する。

例:

```
設定ファイルを開けませんでした
対象: examples/sample.hrn
  Error  viewer.layout.cols: 1 以上の整数ではありません
  Warning  cells[5].image: 0 以上 2 以下で指定してください
他 3 件の問題があります
```

## セルの状態の表示

セルは次の 4 つの状態を持つ。**空欄と読み込みの失敗は、見た目で分ける。**

| 状態 | 意味 | 表示 |
| --- | --- | --- |
| `Ready` | 画像を表示している | 画像 |
| `Empty` | 表示する画像が無い (画像セットが未割り当て、一致するファイルが無い、このページに画像が無い) | 中立の色で `No image` と、理由を 1 行 |
| `Loading` | 読み込み中 | 中立の色で `Loading...` |
| `Failed` | 読み込みに失敗した | `Load failed`、ファイル名、簡潔な理由、`再読込` の操作。空欄と区別できるよう、背景と文字の色を分ける |

- 空欄は、失敗ではなく**通常のケース** (ページ数の不一致など) なので、失敗より弱い表現にする。`再読込` は出さない。
- 失敗したセルは、通常の画像の表示と、明確に区別できる静的な表示へ切り替える。背景は、画像の領域より低彩度の単色で、中央寄せ。
  長いファイル名や理由は、省略して表示する。ファイルのパス全体は、ツールチップで確認できればよい。
- `再読込` は、セルの中から直接行える。失敗した結果を、キャッシュから取り除いてから、再度要求する (取り除かないと、同じ失敗が返る)。
- 失敗や空欄のセルがあっても、セルの枠、ラベル、選択範囲の重ね描きなどの共通の表示は、ほかのセルと同じ規則で出す。パンやズームの操作は受け付けるが、
  見た目は変わらない。**同じページで複数のセルが失敗しても、ほかのセルの表示の更新は続ける。**
- 空欄のセルと失敗したセルは、解析の対象から自動で除外する。画素値の表示では、「画像なし」「読込失敗」と出す。
- 読み込みに失敗したファイルのパスを、一覧で見られるのが望ましい。

### 差分のセルの状態

差分のセルが作れないとき (元のセルの画像がまだ揃っていない、画像の無いセルを指している、など) は、`Empty` の表示で、理由 (`Diff: waiting for Cell 1 and Cell 2.`
など) を出す。
