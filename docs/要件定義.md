# 要件定義

`Heiran` は、複数の画像を並べて表示し、パンとズームを同期させて見比べる、画像の比較ビューア兼解析ツール。
この文書は、実現する機能の要件を定める。要件ごとの状態は、次の記号で示す。

- **済**: 実装済み
- **一部**: 一部を実装済み (残りは [open_tasks.md](../open_tasks.md))
- **未**: 未着手
- **対象外**: 実装しない

仕様の詳細は、それぞれの設計文書にある ([README](./README.md) に一覧がある)。

## 表示

### 並べて同期する

- 複数の画像を、テーブル (行 x 列) の形に並べて表示する。 **済**
- 次の操作を、全セルで同期する。 **済**
  - ドラッグによる平行移動
  - マウスホイールによるズームイン、ズームアウト
- **セルごとに、同期の有効 / 無効を切り替えられる。** **済**
  - 同期が有効なセルを平行移動させたとき、同期が無効なセルは、基準のビューとの差分を記録して動かない。
  - 同期が無効なセルを平行移動させたときは、そのセルだけ、基準のビューとの差分を増減させて動く。
- 全体で同期する**基準倍率**とは別に、セルごとの**個別倍率**を指定できる。 **済**
  - `最終倍率 = 基準倍率 x 個別倍率`
  - 解像度の異なる画像を並べたときに、大きさをそろえるための倍率。
- 表示するセルの数は、1 枚から 16 枚まで。分割できるレイアウトは、枚数に応じて網羅する (1x16、2x8、4x4、8x2、16x1 など)。
  **済** (`Layout` メニューに、セルの数 (1 から 16) ごとの小メニューがあり、その数になる行 x 列を、すべて選べる。`Custom...` では、行 x 列が 16 までの任意の指定)
- 画像を並べる順は、行優先か列優先を選べる。あとから、任意に並べ替えられる。 **済**
- **画像の差分を、セルとして並べて見られる。** 差分のセルも、ほかのセルと同期する。 **済** ([解析機能設計](./解析機能設計.md))

### 画像の指定とページ

- 表示する画像は、グロブ表現で指定できる。 **済**

  ```
  Img1 : img1/*.png
  Img2 : img/*_img2.png
  ```

- グロブに複数の画像がヒットしたら、全セルが同期して、ページを切り替えられる。枚数が足りないセルは、空欄にする。 **済**
- グロブで見つけた画像の並びは、ファイル名の文字列順か自然順から選べる。 **済**
- ページの一覧をドロップダウンで出し、指定したページへ切り替えられる。十字キーの左右でも、ページ送りできる。
  画像一覧をサイドパネルに表示し、サムネイルと詳細 (ファイル名、幅、高さ、ファイルサイズ) を切り替えられる。
  パネル内のお気に入りフィルターと、一覧の選択・ページ送りを連動させる。 **済**
- 一覧の複数選択から画像を並べて比較し、選択した元ファイルを他アプリへコピーのドラッグで渡せる。 **済**
- 選択比較を終了すると、比較を始める前のレイアウトとページに戻れる。 **済**
- セルへのファイルのドラッグアンドドロップで、そのフォルダの同じ拡張子のファイルのグロブで、画像の指定を上書きする。 **済**
- 開いている元ファイルを Ctrl + ドラッグで他アプリへ渡せる。 **済** ([表示状態仕様](./表示状態仕様.md#元ファイルのドラッグ))
- ドロップした画像のページ位置が、現在のページと違うときは、ページ位置が一致するよう、先頭を空で埋めて調整する。 **済**
- 画像ファイルを直接開くこともできる (起動引数、`File > Open Image`、ドロップ)。開いた画像のフォルダを、画像セットとして扱う。 **済**
- 外部差分ツールとして、起動引数で指定された 2 枚の画像とその差分を開ける。左右それぞれに表示名を指定できる。 **済** ([解析機能設計](./解析機能設計.md#差分))
- **ファイルの中の複数の画像**: アニメーション (GIF、WebP、APNG) は、再生とコマ送り。マルチページの TIFF とマルチパートの EXR は、ページ送り。
  ページとフレームは別の軸で、全セルで番号を共有する。 **済**

### ラベル

- 各画像にラベルを設定し、各画像の表示領域に重ねて出せる。 **済**
- ラベルには、ファイルサイズ、幅、高さを展開できる。 **済**

### 拡大と縮小

- 拡大は、最近傍 (`Nearest`) と滑らかな補間 (`Smooth`) から選べる。縮小は、最近傍 (`Nearest`) と面積平均 (`Area`) から選べる。 **済**
  (滑らかな補間は双線形。双三次ではない。)

### 表示設定

- 各画像について、次の表示設定を切り替えられる。全セルへ一括で切り替える機能もある。 **済**
  - チャネル: カラー、グレー (輝度)、R、G、B、A
  - 回転 (90 度単位) と、左右、上下の反転
  - ガンマ (ガンマ 1.0 の画像を、ガンマ 2.2 などで表示する)
  - 白黒反転 (表示される値を反転する)
- **露出** (段数の指定) で、1.0 を超える浮動小数の画像を見られる。全セル共通で、表示だけに効く。 **済**
- チャネルの `YUV`、`Y`、`U`、`V` 表示: RGB から JPEG の変換係数で変換する。 **未**
- アルファチャネルが無い画像は、不透明として扱う。グレースケールの画像は、R、G、B に同じ輝度を割り当てる。
- **色の管理**: 画像の色空間 (埋め込みの ICC、`.hrn` の指定、形式の既定) から、表示先の色空間 (画面のプロファイル) へ変換して表示する。
  レンダリングインテントと黒点補正を選べる。 **済**
- GUI の**カラーテーマ** (System / Light / Dark) を設定できる。画像を出す面は、配色に関わらず、中立な暗い下地にする。 **済**

### 画素値の表示

- マウスの位置の座標と画素値を、全セル分、表示する。値は、解析用バッファの元の精度から読み、`0-255` と `0.0-1.0` の単位を切り替えられる。 **済**
- マウスの位置を、画素値つきで拡大して見られる (ルーペ)。 **済**
- 全セルに、同じ画像座標を指す共有のカーソルを出す。 **済**
- 画像のファイル、画素の形式、色空間、EXIF などのメタデータを、セルを並べて比べられる (画像情報)。 **済**

## 対応する画像形式

| 区分 | 形式 |
| --- | --- |
| 一般 | PNG (16bit、アニメーション APNG を含む)、JPEG、BMP、GIF (アニメーション)、WebP (アニメーション) |
| 次世代 | AVIF、JPEG XL |
| 高精度、制作 | OpenEXR (half、float、パート)、TIFF (8 / 16bit、half、float32、CMYK、マルチページ)、HDR、TGA、DPX、PSD |

- **済**。ライブラリは、形式ごとに最も合うものを直接使う (読み手の一覧と理由は [設計判断](./設計判断.md#画像の読み込み))。
- **HEIC は対象外** (HEVC の特許とライセンスの重さのため)。`pnm` / `pbm` / `pxm`、PDF は、**未** (必須ではない)。
- 8bit だけでなく、16bit の整数、16bit の浮動小数 (half)、32bit の浮動小数 (float) にも対応する。 **済**
- **解析用バッファ**は、元ファイルの画素の精度 (`uint8`、`uint16`、`half`、`float`) のまま保持する。`float32` へは、演算のときに変換し、
  常時 `float32` へ展開して保持しない。表示のための量子化済みの画像と GPU のテクスチャは、別に持つ。
  - 理由: 目的は量子化による情報の欠落を防ぐことで、8bit を `float32` へ広げても情報は増えず、メモリが 4 倍になる。
    複数の画像を並べて比較する用途で、常駐量が過大になる。
- 16bit / 32bit float の画像で、精度が保たれる。 **済**

## 閲覧設定ファイル

- 閲覧する画像を指定する設定ファイルを用意する。人が編集しやすい、コメント付きのテキスト形式で、内部は `JSON5` 相当のオブジェクト構造。
  拡張子は `.hrn`。 **済**
- 詳細な仕様、キー名、サンプルは [設定ファイル仕様](./設定ファイル仕様.md) に従う。
- `.hrn` を Heiran に関連付けられる (インストーラの選択)。起動引数に `.hrn` のパスが渡されたら、その設定を読み込んで起動する。 **済**
- 設定の読み込みに失敗しても、アプリを閉じず、別のファイルを開く導線と、最近使った一覧を出す。 **済**

## 解析

- 画像の領域を選択して、その領域を解析できる。選択範囲は全セルで共有する。 **済**
- **ヒストグラム**: R、G、B のヒストグラムを、全セルで共通の横軸で、並べて表示する。3 次元の RGB ヒストグラムもある。 **済**
- **差分**: 基準のセルと比べるセルを選んで、2 枚の画像の差を出す。絶対値、符号付き、二値、重ね合わせ。数値指標 (最大、平均、RMSE、PSNR、
  閾値を超えた画素の数)。大きさの違う画像は、重なる部分だけ、またはどちらかの大きさへ合わせて比べる。 **済**
- **フォルダ比較**: 相対パスが同じファイルの一致・変更と片側のみのファイルを一覧にし、変更を順に閲覧する。画像は専用の 2 枚差分画面へ、その他は外部差分ビューアーへ渡せる。 **済**
- **変化グラフ**: 縦に平均して横方向の変化、または横に平均して縦方向の変化を、グラフにプロットする。 **済**
- 差分の色差の指標 (ΔE、SSIM)、波形モニタ、ベクトルスコープ。 **未**
- 詳細は [解析機能設計](./解析機能設計.md)。

## フィルタとプラグイン

- 各画像に、任意のフィルタを適用できる。フィルタは、解析用バッファに対して適用し、演算は `float32` で行う。 **未**
- 解析とフィルタを、プラグインで追加できるようにするのが望ましい。 **未**
  - 解析プラグインは、読み取り専用で、画像データを変更しない。フィルタプラグインは、画像データを変換する。
  - 両者は、責務、実行のタイミング、キャッシュの方針が異なるため、別の API として設計する。
  - 外部の API は、内蔵の機能が安定するまで固定しない ([設計判断](./設計判断.md#外部プラグインは作らない-当面))。

## 実装の要件

- 画像にお気に入りのマークを保存し、候補ページだけの表示と、元画像を変更しない一括コピーを行える。 **済**
  詳細は [お気に入り仕様](./お気に入り仕様.md)。

- 言語は C++、GUI は Qt の `QWidget`。 **済**
- 動作環境は、Windows、macOS、Linux のクロスプラットフォームが目標。現在は **Windows (MSVC) だけ**を対象にしている。 **一部**
- 描画は GPU で行い、**OpenGL 3.0 以上に対応した GPU とドライバを、動作の要件とする**。 **済** (`QOpenGLWidget`)
  - ソフトウェアの OpenGL (`opengl32sw.dll`) は、配布物へ入れない (約 21 MB。GPU の無い環境は、ほぼ無いため)。
  - 起動の前に、OpenGL のコンテキストを作れるかと、バージョンを確かめ、使えなければ、理由を知らせて終わる (`HEIRAN_SKIP_OPENGL_CHECK` で、確かめを省ける)。
- 配布は、Windows のインストーラ (NSIS) と ZIP。 **済**
- 基本のアーキテクチャ、責務分割、主要クラスは [アーキテクチャ設計](./アーキテクチャ設計.md) に記載する。
