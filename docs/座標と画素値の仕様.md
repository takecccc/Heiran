# 座標と画素値の仕様

`Heiran` の座標変換と、画素値、ルーペの表示を定める。表示状態の更新規則は [表示状態仕様](./表示状態仕様.md)、
確認の観点は [テスト観点](./テスト観点.md) にある。

## 座標系

- 画像座標系の原点は左上。右が `x` の正、下が `y` の正。
- 画像内の位置、選択範囲、マウスの位置、解析の対象の矩形は、この座標で統一する。

## 変換の順

画像から画面までの変換は、次の順で適用する。

1. EXIF の向き (`honor_exif_orientation` が真のとき)
2. 利用者が指定した回転
3. 利用者が指定した左右反転
4. 利用者が指定した上下反転
5. 拡大縮小
6. 平行移動

### EXIF の向き

- JPEG などの EXIF の向きは、適用するかを画像ごとに切り替えられる (既定は適用)。
- 真のときは、デコーダが向きを適用した画像を返す。EXIF の向きは、利用者の回転と反転より**先**に適用する。
- 偽のときは、EXIF の向きを無視して、格納された配列のまま扱う。
- 適用した向きは、復号結果へ記録する。画素値の表示では、**解析用バッファは EXIF を適用した後の並び**のまま読み (値がずれないように)、
  表示する座標の文字列だけを、元のファイルの座標へ戻す。

### 回転と反転

回転と反転は、画像座標から表示座標へ写す前段の変換。順は、回転、左右反転、上下反転で固定する。
画像の大きさを `width`, `height` とすると、整数の画素座標 `(x, y)` に対し、回転は次で定義する。

| rotation | rx | ry |
| --- | --- | --- |
| 0 | `x` | `y` |
| 90 | `height - 1 - y` | `x` |
| 180 | `width - 1 - x` | `height - 1 - y` |
| 270 | `y` | `width - 1 - x` |

回転の後の大きさは、`0` と `180` では `width x height`、`90` と `270` では `height x width`。
反転は、回転の後の座標に適用する。

- `flip_x`: `fx = rotated_width - 1 - rx`
- `flip_y`: `fy = rotated_height - 1 - ry`

逆変換は、この逆の順で戻す。先に反転して回転した結果とは、一般に違う。

### 表示座標との対応

回転と反転を除いた基本の形は、次のとおり (`view_x` と `view_y` は、セル内の表示座標)。

- `view_x = (image_x - final_offset_x) * final_scale`
- `image_x = view_x / final_scale + final_offset_x` (`y` も同様)

### 画素の選び方

マウスの位置から画素値を取るときは、逆変換で得た浮動小数の座標を、`floor` で整数の画素位置へ変換する (左上原点の画素の解釈と整合し、境界での
ちらつきを抑えられる)。

## 選択矩形

- 選択の開始点と終了点から、画像座標へ逆変換した後、`x0 = min(start_x, end_x)`、`x1 = max(...)`、`y` も同様に正規化する。どの向きにドラッグしても、
  同じ矩形になる。
- 矩形は**半開区間** `[x0, x1)`, `[y0, y1)` で扱う (画素数の計算が単純で、Qt の矩形の表現と整合する)。
- 共有選択範囲は、基準にしたセルの画像座標で持ち、他のセルへは再投影する ([解析機能設計](./解析機能設計.md#共有選択範囲))。

## 画素値の表示

- マウスを乗せているセルについて、**全セル分**の値を並べて出す。ドック (Pixel Info) に出し、既定では閉じている。
- 値の取得元は、**解析用バッファ** (表示用の画像ではない)。取得する座標は、回転、反転、EXIF の向きを戻した、元の画像の座標で求める。
- 出すもの: 画像座標 `x`, `y`、現在のページ番号、セル名か画像のラベル、チャネルごとの値。
  - グレー系の画像: `Gray`
  - RGB 系: `R`, `G`, `B`
  - RGBA 系: `R`, `G`, `B`, `A`
  - 表示のチャネルが 1 つだけでも、画像が持つ使えるチャネルを、まとめて出す。
- 輝度は、色空間から導いた重みで求める ([解析機能設計](./解析機能設計.md#基本方針))。

### 表示の単位

- 取得元の精度に関わらず、**同じ単位**で出す (ビット深度の違う画像を並べても、値を直接比べられる)。
- `0-255` (既定) と `0.0-1.0` を切り替えられる。単位は、セッションではなく、アプリ全体の設定に保存する。
  - `0-255`: 正規化した値を 255 倍して、小数 3 桁。8bit の画像では、従来と同じ整数部になる。16bit の 1 階調は `255/65535 = 0.0039` で、
    小数 3 桁で分解できる。
  - `0.0-1.0`: 小数 5 桁。16bit の 1 階調は `1/65535 = 0.0000153` で、分解できる。
- 浮動小数の画像では、1.0 を超える値と負の値を、そのまま出す。列を揃えるため、桁数は固定する。

### 境界と、画像のないセル

- 逆変換した座標が画像の範囲の外なら、「範囲外」と出す。右端と下端ちょうどの座標は、半開区間の考え方で、範囲外。
- 空欄のセルと読み込みに失敗したセルでは、値を更新せず、「画像なし」「読込失敗」と出す。

### 更新の契機

次の場合に更新する: マウスの移動、ページの切り替え、チャネルの変更、回転と反転の変更、画像の読み込みの完了。
パンとズームだけでは、必須ではない (パンとズームの後は、同じ画面座標が別の画像座標を指すため、再計算するのが自然だが、主役はマウスの移動)。

## ルーペ

- マウス近傍の画素を拡大して見せる補助のビュー (メインウィンドウの Pixel Info のドック)。操作中のセルに対してだけ行う。
- 中心は、マウスの下の画素。中心の画素を識別できるガイドを出す。拡大は最近傍で、個々の画素の境界が分かるようにする。
- パンやズームをしても、ルーペが参照する元の画素は、マウスの位置に対応する画像座標に追従する。
- ページを切り替えたときは、同じマウスの位置に画像がある場合だけ更新する。空欄のセルと範囲外では、クリアするか「対象なし」を出す。
- 共有選択範囲があっても、ルーペの中心は、常にマウスの位置を優先する。

## 共有カーソル

- 参照中の画素の位置を、全セルに共有のカーソルで示す。100% 以上では、画素の中心へ合わせた、中央を空けた十字 (中心を空けるのは、指している
  画素そのものが隠れて色を確かめられなくなるため)。縮小のときは、位置だけを指す。
- 線は、暗い縁の上に色の線を重ねる (View > Cursor で、画素の色から離れた色を選ぶ方式にもできる)。
