# 設定ファイル仕様

`Heiran` の閲覧設定ファイル (`.hrn`) の仕様を定める。検証の失敗の見せ方は [エラー処理仕様](./エラー処理仕様.md)、
形式を選んだ理由は [設計判断](./設計判断.md#設定ファイル-hrn) にある。

## 形式

- 人が編集する前提で、コメントを書ける。内部の形式は `JSON5` 相当 (コメント、キーの引用符の省略、単一引用符、末尾のカンマ)。
  パースした後は、通常のオブジェクト構造として扱う。
- 拡張子は `.hrn`。Heiran に関連付けられる。起動引数に `.hrn` が渡されたら、その設定を読み込んで起動する。
- 相対パスは、設定ファイルのあるディレクトリを基準に解決する。
- ルートに `format_version` を持つ。

## 設計方針

- 並列の配列 (`names`、`paths`、`scales` など) は使わず、1 画像ごとに 1 つのオブジェクトを持つ。
- キー名は、意味を保ったまま短くする。
- 省略できる値は `defaults` にまとめ、各画像の設定で上書きできる。
- 解析プラグインとフィルタプラグインは、別の設定の領域で管理する。

## `format_version`

- 対応するのは `1`。省略されたときは `1` とみなす。
- `1` より大きいときは、将来の版の可能性があるため、警告つきで読み込みの失敗とする。`1` 未満、または数値でないときは、不正として失敗にする。
- 前方互換より、誤った解釈を防ぐことを優先する。

## 検証と問題の報告

- 意味の検証では、問題を、**設定の項目ごとに集約**して報告する (最初の問題で打ち切らない)。上限は 20 件で、超えた分は打ち切り、その旨を要約に含める。
- 問題は 2 段階。
  - `Error`: 読み込みを失敗として扱う。`format_version` の不正、必須キーの欠落、レイアウトのセル数の超過など、既定値で読み替えると意図と
    異なる結果になるもの。
  - `Warning`: 既定値へ読み替えて続行する。範囲外の `rotation`、未知の `ch`、存在しない `image` の参照、不正な `diff` など。
- 位置は、`cells[1].rotation` のように、項目の位置が分かる形で示す。
- **構文エラー**は、最初に検出した 1 件を、読み込みの失敗の理由とする。構文の解析に成功した後の意味の検証だけを、複数件まとめる。
- 集約の単位は、「利用者が 1 回の修正で直せる、最小の設定項目」。同じキーから複数の派生のエラーが出るときは、原因に近い 1 件だけを採る。
  配列の要素の問題は、`images[2].path` や `cells[5].image` のように、要素単位で報告する。参照の不正は、不正な参照の項目ごとに 1 件。
- グロブが 0 件のときは、警告として扱い、ファイル自体は開ける。
- **未知のキー**: `format_version = 1` の範囲では、既知の構造の中に未知のキーがあっても、警告なしで無視する。無視したキーは、内部のモデルにも、
  保存の出力にも引き継がない。既知のキーの型の不一致と、構造の不一致は、エラー。

## ルート構造

```json5
{
  format_version: 1,
  defaults: { ... },
  viewer: { ... },
  images: [ { ... } ],
  cells: [ { ... } ],
  plugins: {            // 仕様のみ。読み込みと保存は、まだ対応していない
    analysis: [ ... ],
    filters: [ ... ],
  },
}
```

| キー | 内容 |
| --- | --- |
| `format_version` | 設定ファイルの形式の版 |
| `defaults` | 画像の設定の既定値 |
| `viewer` | ビューア全体の設定 |
| `images` | 画像セット (画像の系列) の定義 |
| `cells` | セルごとの表示設定 |
| `plugins` | プラグインの設定 |

### `images[]`

- `name`: 画像セットの名前
- `label`: セルの左上に重ねるラベルのテンプレート
- `path`: グロブの指定
- `scale`: 個別倍率 (画像セットの既定の倍率。セルへ割り当てるときに、セルの倍率へ写す)
- `page_offset`: 先頭のファイルが、全体の何ページ目に対応するか
- `label_visible`: ラベルを出すか。既定は出さない。
- `honor_exif_orientation`: EXIF の向きを適用するか (既定は `true`。`false` のときは、デコーダが向きを適用せず、格納された配列のまま返す)
- `color_space`: 色空間の上書き。省略か `auto` で、埋め込みのプロファイルと形式の既定に従う
- `icc_profile`: ICC プロファイルの経路。指定があれば、`color_space` より優先する。`.hrn` からの相対で書ける

`color_space` に指定できる名前: `srgb`、`srgb-linear` (`linear` も同じ)、`display-p3`、`adobe-rgb`、`rec2020`、`prophoto-rgb`、
`bt2100-pq`、`bt2100-hlg`。

色空間の決め方: `icc_profile` が読めればそれ。読めなければ `color_space`。それも無ければ、埋め込みのプロファイル。それも無ければ、
浮動小数で値を持つ形式 (OpenEXR、Radiance HDR) は線形、それ以外は sRGB とみなす。

`label` で使えるプレースホルダ: `{filesize}`、`{filesize:KB}`、`{filesize:MB}`、`{filesize:GB}`、`{width}`、`{height}`。
幅と高さは元の画像、ファイルサイズは現在のページの実ファイルを基準に展開する。

### `cells[]`

- `image`: `images` の参照先の番号 (0 から)。省略か範囲外は、空のセル
- `sync`: 同期の有効 / 無効
- `scale`: セルごとの個別倍率
- `gamma`: セルごとのガンマ
- `rotation`: 回転。`0`、`1`、`2`、`3` が、`0`、`90`、`180`、`270` 度
- `flip_x`、`flip_y`: 左右、上下の反転
- `invert`: 白黒反転 (露出とガンマを適用して丸めた後の、表示される値を反転する)
- `ch`: チャネルの表示。`color`、`gray`、`red`、`green`、`blue`、`alpha`
- `diff`: あれば、このセルは画像ではなく**差分**を見せる (省略できる)
  - `base`: 基準にするセルの番号 (0 から。このセル自身は不可)
  - `target`: 比べる側のセルの番号。省略すると、このセル自身の `image` (表示が差分に置き換わる)。画像の無いセルでは必須。`base` とは別のセルを指す
  - `mode`: `absolute` (既定) / `signed` / `binary` / `delta-e` (色差 CIEDE2000。輝度ではなく RGB 全体の色の違い) / `ssim` (構造的類似度。輝度の局所の構造の違い。見せるのは 1 - SSIM) / `wipe` (差ではなく、2 枚を境目で切って、つなぎ合わせる)
  - `view`: `grayscale` (既定) / `signed-color` / `overlay`
  - `gain`: 差の倍率 (既定 1.0)
  - `threshold`: `binary` と「超えた画素」の閾値。輝度の 0-255 の尺度 (既定 8)。`delta-e` のときは ΔE の単位 (目安は 2.3)。`ssim` のときは、SSIM の値 (これを下回った画素を数える。目安は 0.9)
  - `auto_range`: 差の最大が 255 になるよう、倍率を自動で合わせるか (既定 `true`)
  - `size_match`: 大きさの違う画像の扱い。`overlap` (既定。左上をそろえて、重なる部分だけを比べる。以前の名前 `off` も読める)、`base` (比べる側を基準の大きさへ)、
    `target` (基準を比べる側の大きさへ)、`larger` (面積の小さいほうを大きいほうへ。細部を捨てない)
  - `wipe_direction`: ワイプの切り方。`left-right` (既定。左が基準、右が比べる側) / `top-bottom` (上が基準、下が比べる側)。`mode` が `wipe` のときだけ、保存する
  - `wipe_position`: ワイプの境目の位置。画像の幅 (`top-bottom` では高さ) に対する 0.0-1.0 (既定 0.5)。範囲外は、範囲へ収める
  - 差分は、他のセルが見せている画像から作る。差分のセルを元にはしない。不正な値は、警告を出して、差分の指定を捨てる。
  - 詳細は [解析機能設計](./解析機能設計.md#差分)。

### `viewer`

- `layout.rows`、`layout.cols`: 行数と列数
- `layout.order`: `row-major` か `col-major`
- `page_sort`: `lexical` か `natural`

## 既定値

- `images[].scale`: `1.0`。`cells[].sync`: `true`。`viewer.page_sort`: `natural`。`honor_exif_orientation`: `true`。
- セルの設定を省略したときは、画像セットの順に、1 つずつ割り当てる。

## サンプル

```json5
{
  // 設定ファイル形式のバージョン
  format_version: 1,

  defaults: {
    scale: 1.0,
    sync: true,
    label_visible: true,
    honor_exif_orientation: true,
  },

  viewer: {
    layout: {
      rows: 2,
      cols: 2,
      order: "row-major",
    },
    page_sort: "natural",
  },

  images: [
    {
      name: "Img1",
      label: "Image A {filesize:MB}",
      path: "img1/*.png",
    },
    {
      name: "Img2",
      label: "Image B {width} x {height}",
      path: "img/*_img2.png",
      scale: 0.5,
      label_visible: false,
      honor_exif_orientation: false,
    },
    {
      name: "Img3",
      path: "img/*_img3.png",
    },
  ],

  cells: [
    { image: 0, sync: true, scale: 1.0, gamma: 1.0, rotation: 0, ch: "color" },
    { image: 1, sync: true, scale: 0.75, gamma: 1.2, rotation: 0, ch: "green" },
    { image: 2, sync: false, scale: 1.0, gamma: 1.0, rotation: 1, ch: "gray" },
    // 空きのセルへ、Img1 と Img2 の差分を出す
    { diff: { base: 0, target: 1, mode: "signed", view: "signed-color" } },
  ],
}
```

## 保存

- 保存のときは、内部のモデルから、正規化した `JSON5` のテキストを作り直す。**読み込んだときのコメント、空行、キーの順、未知のキーは、保存の後に残らない**
  (構文木を保って部分的に更新する実装は複雑で、読み込みの堅牢性と内部モデルの一貫性を優先した)。
- 整形: UTF-8、改行は LF、インデントは半角スペース 2 つ、末尾の改行あり、末尾のカンマは許容。
- キーの出力順: `format_version`、`defaults`、`viewer`、`images`、`cells`、`plugins`。各オブジェクトの中も、この仕様の順。
- 既定値と一致する項目も、必要な既知の項目は明示して出力する (読み込んだ後に保存すると、既定値が明示されることがある)。可読性と安定性を優先し、
  人の編集の差分が安定する。ただし `color_space` と `icc_profile` と `diff` は、指定が無いときは書かない (空の値を書くと、`auto` ではないように見える)。
- 保存する状態: セルごとの表示状態 (倍率、ガンマ、回転、反転、白黒反転、チャネル、同期、差分の指定)。
  **保存しない**状態: パン、ズーム、現在のページ、共有選択範囲、露出 (一時的な状態。未保存の印にも含めない)。

## アプリ全体の設定

### 画像一覧の表示

サムネイル・詳細とも Ctrl で選択を追加・解除し、Shift で範囲選択できる。表示方法を切り替えても選択を保持する。
複数選択中は画像のプレビューやページ送りで選択を解除しない。単独の選択では選んだページへ移動する。
「選択画像を並べる」で一覧順に 2～16 ファイルを同じウィンドウのセルへ配置し、フィットする。
画像を直接複数開く場合と同じフォルダー内の連番・ページ対応を使う。配置変更は「元に戻す」で戻せる。
選択した行・サムネイルをドラッグすると、存在する元ファイルの URL を重複なく一覧順に他アプリへ渡す。
ドラッグはコピーのみを許可し、元ファイルは移動しない。一覧内の並べ替えやドロップ受け入れは行わない。

パネル名は「画像一覧」とし、内部の表示方法を「サムネイル」「詳細」で切り替える。
「お気に入りのみ」は既存の画像の絞り込みと同じ状態を操作し、メニュー、ショートカット、ページ送りと連動する。
詳細表示はページの代表ファイルの名前、幅、高さ、ファイルサイズを表示する。
お気に入り状態は、サムネイルのキャプションに★を付け、詳細表示では先頭の★列に示す (未登録は `—`)。
比較中は可視セルのいずれかにお気に入り画像があるページを★にし、既存のページ絞り込みと判定をそろえる。
登録・解除は画像や情報を読み直さず、一覧の表示へ即時に反映する。
寸法は先頭の画像を対象にし、画像情報の取得は UI スレッドの外で行う。取得できない値は `—` とする。
詳細表示ではサムネイルを生成せず、表示方法は INI の `display/imageListMode` に保存する。

「表示 > 画像一覧」、ナビゲーションの一覧ボタン、`T` でサイドパネルの表示を切り替える。
初回は左側に表示し、左右へのドッキングと幅の変更、閉じる操作を許す。独立したウィンドウへは切り離さない。
配置、幅、表示状態は既存のウィンドウ配置設定に含める。
一覧の選択でページへ移動し、ページ送りでも一覧の選択を更新する。一覧は閉じない。
現在の可視セルからページを代表する画像を選び、お気に入りの絞り込みにも追従する。
対象がないときもパネルは開け、空表示にする。パネルが隠れている間は新規読み込みを始めず、進行中の要求を取り消す。
詳細へ切り替えるとき、幅が狭い場合は列を読める幅へ広げる。その後は境界で幅を調整できる。
画像セットの変更時に以前の読み込み結果を新しい一覧へ反映せず、前の処理の完了を UI スレッドで待たない。

### 保存する項目

`.hrn` とは別に、利用者に属する設定を `QSettings` に保存する。どの `.hrn` を開いても同じであってほしいものだけを置く。セッションごとに変わる設定は、
`.hrn` に持つ。

Windows では `QSettings::IniFormat` を使い、ユーザースコープの保存先を
`QStandardPaths::GenericDataLocation` (LocalAppData) にする。
設定と履歴は `%LOCALAPPDATA%\Heiran\Heiran.ini` に保存する。
レジストリの既存設定は読み込まず、移行しない。INI が無い場合は既定値から開始する。
ファイル関連付けなど Windows への登録に必要な情報だけをレジストリに持つ。

その他のユーザーデータも `%LOCALAPPDATA%\Heiran` 配下へそろえる。
`infra::userDataDirectory()` が共通の基準ディレクトリを返し、組織名とアプリ名を重ねない。
お気に入りは `favorites.json`、サムネイルは `cache/thumbnails/`、クラッシュダンプは `crashes/` に置く。
旧ディレクトリ内のファイルは移動・削除しない。キャッシュは必要時に再生成する。

設定ダイアログは、左側で「全般」「表示・再生」「色管理」「キャッシュ」を選び、右側に対応するページを表示する。
全般には言語と配色、表示・再生には画素値の単位、ページ切り替え時のフィット、セルの枠、透過背景、補間、アニメーションの同期を置く。
色管理にはプロファイル、変換方法、黒点補正、解析値の空間を、キャッシュにはメモリ上限とストリーミングの境目を置く。
初期ページは全般。ページの変更だけでは設定を適用せず、全ページの編集を保持する。
OK で全ページをまとめて確定し、キャンセルと閉じる操作ではすべて破棄する。右側だけを必要に応じてスクロールし、確定・キャンセルのボタンは常に下部へ表示する。
右側のページと確定ボタンの間に、高さを固定した説明領域を置く。マウスが指している項目 (ラベルを含む) と、キーボードでフォーカスした項目の名前・説明を表示する。
入力部品の内部へフォーカスした場合も、その項目を案内する。無効な項目もマウスで説明を読める。
項目から離れても最後の説明を保持し、長い説明は領域内でスクロールする。初期状態では操作案内を表示する。
次回起動からの反映、これから開くファイルへの適用、機能を選択できない理由は、項目の近くにも常時表示する。

- 最近使った `.hrn` の一覧、最近開いた画像の履歴
- 画素値の表示の単位 (`0-255` / `0.0-1.0`)
- ページ切り替え時にフィットするか
- セルの枠線を出すか
- セルのヘッダーを出すか (`display/showCellHeaders`、既定は表示)。全セル共通で、画像や格子を変更しても維持する。
  `View > Cell Headers` で切り替え、画像表示面の大きさの変化には通常のフィット追従を適用する。
  ナビゲーションを非表示にしたときは、ステータスバーの右側に前後移動とページ選択を残す。
- デコードキャッシュのソフト上限 (MiB)、GPU テクスチャの上限 (MiB。全セルの合計)、アニメーションを逐次展開する境目 (MiB)
- アニメーションの再生方式 (`Auto` / `Locked` / `Independent`)
- 拡大と縮小の補間
- 表示先の色空間の決め方 (画面のプロファイル / sRGB 固定 / ICC ファイル) と、ファイル指定のときの経路
- レンダリングインテントと黒点補正
- 解析値の空間 (ファイルのまま / 線形光)
- 配色 (System / Light / Dark)
- 透過部分の背景 (単色 / 市松模様)、単色の色と市松模様の 2 色。既定は単色 `#f5f5f5`。
  市松模様の既定の色は `#c0c0c0` と `#f5f5f5`。色は不透明な RGB とし、不正な保存値は項目ごとに既定値へ戻す。
  背景の設定は全セルとルーペに適用し、OK で確定後すぐに反映する。方式を切り替えても各色を保持する。
  セルの背景領域を含む描画面の右クリックメニューでも「透過部分の背景」から単色 / 市松模様を切り替えられる。
  選択した方式はすぐに全セルとルーペへ反映して保存する。空のセルでも選択でき、セッションの変更には数えない。
- 共有カーソルの描き方 (縁つきの固定色 / 画素から離れた色)
- ウィンドウの大きさと配置

環境変数 `HEIRAN_DECODE_CACHE_BUDGET_MB` と `HEIRAN_GPU_TEXTURE_BUDGET_MB` は、設定より優先する (設定を変えずに、一時的に試すため)。
