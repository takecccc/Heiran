# 表示状態仕様

`Heiran` の表示状態と、同期の規則を定める。座標変換と画素値の表示は [座標と画素値の仕様](./座標と画素値の仕様.md)、
エラー時の表示は [エラー処理仕様](./エラー処理仕様.md)、確認の観点は [テスト観点](./テスト観点.md) にある。

## 状態モデル

表示状態は、次の 3 つで持つ。

- `GlobalViewState`: 同期が有効なセルが共有する基準の状態。
- `CellViewState`: セルごとの差分と表示の設定。
- 共有選択範囲: 全セルで共有する選択矩形 ([解析機能設計](./解析機能設計.md#共有選択範囲))。

### `GlobalViewState`

- `base_scale`: 基準倍率
- `base_offset_x`, `base_offset_y`: 画像座標系での、表示原点の位置
- `current_page`: 現在のページ。**同期を切ったセルでも、ページ番号は全体で共通。**

### `CellViewState`

- `sync_enabled`: 同期の有効 / 無効
- `offset_delta_x`, `offset_delta_y`: 基準のオフセットとの差分
- `scale`: 個別倍率
- `honor_exif_orientation`: EXIF の向きを適用するか
- `rotation`: 回転 (90 度単位。`0` から `3`)
- `flip_x`, `flip_y`: 左右、上下の反転
- `gamma`: 利用者が指定するガンマ
- `invert`: 白黒反転
- `channel`: 表示チャネル (`color`、`gray`、`red`、`green`、`blue`、`alpha`)。`.hrn` の `ch` に対応する。

`base_offset` と `offset_delta` は、**個別倍率の適用前の正規化座標**で持つ。

### 最終の表示値

- `final_scale = base_scale * cell.scale`
- `final_offset_x = (base_offset_x + cell.offset_delta_x) / cell.scale`
- `final_offset_y = (base_offset_y + cell.offset_delta_y) / cell.scale`

### 表示に適用する順

色の管理が有効なときは、次の順で当てる。詳細は [画像表示設計](./画像表示設計.md#表示の変換)。

1. 線形光へ戻す
2. 原色を表示先へ移す
3. **露出** (全セル共通)
4. 表示先の符号化
5. **ガンマ**
6. **白黒反転**

色の管理が無効なときは、符号化された値へ、露出、ガンマ、白黒反転の順に当てる。

- 白黒反転の対象は、**表示される値**。`1.0` を超えて丸められた画素は、反転すると黒になる。
- **画素値の表示、ヒストグラム、差分は、露出、ガンマ、白黒反転の影響を受けない** (解析用バッファの値を使う)。

## 同期の更新規則

### 同期有効のセルをパンしたとき

`GlobalViewState` の `base_offset_x`, `base_offset_y` だけを更新する。同期無効のセルは `offset_delta` を保持したままなので、
見た目の上では動かない。

### 同期無効のセルをパンしたとき

対象のセルの `offset_delta_x`, `offset_delta_y` だけを更新する。ほかのセルと `GlobalViewState` は更新しない。

パンのドラッグ量は、`final_scale` ではなく `base_scale` で割って、正規化座標へ変換する (個別倍率の差は、`final_offset` の計算で吸収する)。

### ズームしたとき (同期の有無に関わらず)

`GlobalViewState` の `base_scale`, `base_offset_x`, `base_offset_y` を更新する。ズームは**全セルへ反映**する。
`sync_enabled` は、パンの差分を独立させるかだけに影響し、ズームの反映先には影響しない。

- ズームの中心は、操作したセル上のマウスの位置。その画面位置に対応していた画像座標が、ズームの後も同じ画面位置に残るよう、
  `base_offset` を計算し直す。
- 固定点は、操作したセルの画像座標を `image_position * cell.scale` で正規化座標へ変換して使い、有効なオフセットは
  `base_offset + offset_delta` として扱う (計算の後、`offset_delta` を引いて `GlobalViewState` へ戻す)。

### 同期を無効にしたとき

切り替える時点の見た目を保つため、次を設定する。既存の `scale` は、そのまま保持する。

- `offset_delta_x = final_offset_x - base_offset_x`
- `offset_delta_y = final_offset_y - base_offset_y`

### 同期を有効に戻したとき

セル固有の `offset_delta` と `scale` は、**変更しない** (破棄しない)。同期の有効 / 無効は、「基準の状態の更新の対象に含めるか」の切り替えで、
セルが持っていた個別の差分そのものは捨てない。

### ページを切り替えたとき

- `current_page` を更新する。各セルの `offset_delta` と `scale` は保持する。
- 画像が存在しないページは、空欄にする (エラーではない)。長さの違う画像セットを並べたとき、ファイルの中のページ (TIFF など) は、
  最後のページで止まり、アニメーションは巻き戻る ([設計判断](./設計判断.md#ファイルの中の画像-ページとフレーム))。
- 共有選択範囲は、座標を保持する。

### リセット

- セルの右クリックの `Reset Cell Display` は、そのセルの個別倍率、ガンマ、回転、反転、白黒反転を、設定の値へ戻す。**同期とパンの差分は触らない。**
- ビュー全体のリセットは、基準の状態とパンの差分も消す。

## セルへのフィット

表示中の画像を、セルの表示領域に収める。

- **基準倍率は、全ての対象がセル内に収まる値。** 最も制約の強い対象に合わせるため、ほかの対象も必ず収まる。
- 基準オフセットは、制約になった対象を、セルの中央に置く位置。
- **セルごとのパンの差分は、変更しない** (位置合わせのために付けた差分を、フィットで消さない)。
- 画像は非同期で読み込まれるため、読み込み中のセルがある間は適用を保留し、**対象が揃った時点**で適用する。読み込み済みのページへ移る
  ときは、ページを替えた側で、その場で適用する。
- 読み込みに失敗したセルと空欄のセルは、対象に含めない。
- 画像を直接開いたときは、設定に関わらず、フィットする。
  ウィンドウを表示する前に読み込みが終わっても、フィットは表示後のレイアウトが確定するまで保留する。

**ページを切り替えるたびにフィットするモード**を持つ。

- 既定は無効。有効にすると、ページの切り替え時、画像セッションを開いたとき、画像を直接開いたときに、フィットする。
- 設定は、セッションではなく、アプリ全体の設定に保存する。
- モードが無効でも、任意の時点でフィットさせる操作 (`F` キー、ツールバー) は行える。
